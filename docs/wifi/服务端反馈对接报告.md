# 服务端反馈对接报告（休眠设置 · 消息中心 · 轮播 · 删除）

> 日期：2026-10-27｜分支：`main-wifi`｜依据：[V1.4 对接实现报告 · 服务端反馈](V1.4对接实现报告反馈.md)｜改动明细见 [变更记录](../changes/2026-10-27-WiFi版休眠设置与消息中心.md)

## 一句话

WiFi 设备详情新增「休眠设置」和「消息中心」两个入口；轮播设置回显更准确、保存后屏幕立即切图；删除照片的提示以服务端结果为准。

## 改了什么

| 项 | 以前 | 现在 |
|---|---|---|
| 休眠设置 | 没有 | 设备详情新入口：可设「关闭 / 每天定时 / 只休眠一次」，进页面能看到当前设置 |
| 消息中心 | 没有 | 设备详情新入口，带未读数角标；能看设备上下线、电量、投屏成功 / 失败等消息 |
| 轮播回显 | 没选过照片时一张都不勾 | 没选过 = 轮播全部照片，页面显示为全选 |
| 轮播不选照片 | 不选也能保存（= 轮播全部） | 一张不选不能保存，提示「请至少选择一张照片」 |
| 轮播保存后 | 等下一个轮播时间才换图 | 保存后屏幕立即切到第一张选中的照片 |
| 删除照片提示 | 统一提示「已从相框播放列表移除」 | 服务端切了图时提示「已删除，相框已切换到下一张」 |

## 各功能说明

### 休眠设置

- 打开页面先显示当前设置：「未开启休眠」/「每天 22:00 ~ 次日 07:00」/「只休眠一次：开始 ~ 结束」/「已关闭休眠」。
- 三种方式：
  - **关闭**：弹窗确认后关闭；
  - **每天定时**：选休眠、唤醒两个时间，不能相同；唤醒早于休眠时按第二天唤醒；
  - **只休眠一次**：选开始、结束的日期和时间，开始要早于结束，结束不能已经过去。
- 时间都按手机本地时间填，不用换算。
- 设置时设备需要在线：离线、休眠中、已关机会分别提示；填错时显示服务端给的原因。

### 消息中心

- 设备详情入口上显示未读条数（超过 99 显示 99+）。
- 列表按时间从新到旧，每次加载 20 条，下拉刷新、上拉加载更多，不会出现重复的消息。
- 可以只看未读。
- 点一条未读消息即标为已读，角标减 1；也可以一键「全部已读」。
- 有新消息时列表和角标自动刷新，不用手动刷新。
- 能看到的消息：设备上线 / 离线、电量低、WiFi 信号弱、TF 卡将满、投屏成功、投屏失败（下载失败 / 存储异常 / 其他）、设备异常；不认识的消息显示「设备消息」。

### 轮播设置

- 再次进入时，上次选的照片保持勾选和顺序；没选过（轮播全部）显示为全选；之前选的照片都被删了会提示重新选择。
- 轮播中改选照片不用先暂停，直接保存。
- 按相册原顺序全选时，保存为「轮播全部照片」，以后新上传的照片也会自动加入轮播。
- 保存成功后屏幕立即切到第一张（选中的第一张；全选时是相册第一张）。

### 删除照片

- 删除流程不变（先删相册记录，再删云端文件），提示以服务端返回为准：
  - 服务端切到了下一张 →「已删除，相框已切换到下一张」；
  - 设备离线 →「已删除；设备离线，相框换图将在设备联网后进行」；
  - 其他 →「已从相框播放列表移除，设备联网后更新」。

## 需要注意

| # | 事项 | 影响 |
|---|---|---|
| 1 | 保存轮播后立即切图那一张，会另外生成一个图片文件，不进「我的上传」 | 相册里不会多一张；不影响后续轮播和删除 |
| 2 | 「轮播后休眠」导致的设备断开，服务端可能显示「离线」并发离线消息 | 待固件确认断开方式后由服务端调整，前端不用改 |
| 3 | 轮播中平台不知道屏上是哪张，删除范围内的照片服务端会强切下一张，可能多刷一次屏 | 服务端后续用「设备下载记录」反推当前图后可消除 |
| 4 | 反馈中确认项 1、2、5 本次不展开 | — |
