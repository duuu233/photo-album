# 文档归档

> 状态：current  
> 最后核对：2026-07-28

本目录保存已经完成、被取代或只代表某个历史时点的文档。

归档文档用于回答“当时发生了什么、为什么做出某个决定”，不能自动作为当前实现或当前产品口径。需要了解现状时，从上级 [项目知识地图](../README.md) 进入对应的 architecture、protocols、decisions 或 reference 主文档。

目录约定：

- `designs/`：已不再采用的目标方案；
- `handoffs/`：跨仓库/跨端交接快照；
- `incidents/`：问题排查和历次修复过程；
- `performance/`：性能计划、基线和实验记录；
- `progress/`：阶段性接入进度；
- `reviews/`：代码审查及处置清单；
- `superseded-designs/`：已被新设计取代的交互或架构。
