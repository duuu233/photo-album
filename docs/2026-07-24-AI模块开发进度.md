## 已实现功能

聊天页（chat）：
- 星宝招呼语默认态（需求原文案）；消息气泡流（用户右/AI 左）
- AI 回复：占位气泡三点 loading → **客户端打字机 30ms/字**（小程序不支持 SSE，走非流式 URL，文档 §四/§6.4）
- 生成图片以图片气泡展示，点击预览，`lazy-load`
- 「停止生成」浮标：中断 wx.request（`requestTask.abort`）+ 结束打字机，已打出内容保留
- 输入区：文本输入+发送；🎤 切换「按住说话」（录音已接 RecorderManager，**转文字待开通同声传译插件**，先占位提示）
- ＋工具面板：相册 / 拍照 / 一键生图（漫画·风景·肖像·动漫 → img_style）/ 图片比例（竖·横·方 → img_orientation，必传，默认竖向）
- **图文多模态（v1.0.3，2026-07-25 改）**：相册/拍照选图（相册可多选，最多 4 张）→ `api.setFileUpload` 上传拿 URL →
  缩略图停在**输入框内**（每张可删、上传中转圈、纯图片不可发）→ 输入文字点发送，随 `image_urls` 一起走 `/chat`，
  服务端按张数+关键词分流（图生图/多图讨论/友好拒绝）。〔旧「下一条输入=`/image/enhance`」单图链路已下线〕
- 长按消息：文本→删除；图片→下载（存相册，拒权引导设置）/ 投屏 / 删除
- 投屏：已连接活动设备→直接进投屏；未连接→弹已绑定设备列表→选中后走投屏。实现方式：AI 图下载成临时文件，包装成与手选照片同形态的 `pendingProjection` 跳 `projection/preview`，预热连接/自动连接/图传全部复用现有链路
- 会话标题：首条消息后本地同步为消息内容（与后端 title 行为一致）
- Token 余额展示 + 每次成功对话扣 1 + 余额不足弹窗拦截（**本地 demo 模拟**，Java 后端支付体系未接）
- 无绑定设备拦截（API 文档 §5.5）：进页检查，未绑定弹「去绑定」
- 封禁（22002/22003）：弹窗 + 禁用输入 + 顶部横幅

会话列表页（sessions）：
- 时间倒序；标题=首条消息；今天显示 HH:mm，其余 MM-DD HH:mm
- 分页每页 20 条滚动加载（接口一次回全部，前端分段展示）
- 长按删除单条（需求"左滑或长按"取长按）；清空全部二次确认（接口无批量删，逐条删）
- 新建会话；删除/清空当前打开的会话时通知聊天页重置
- 「仅保留最近 7 天」提示；历史过期 code=10001 → toast `info.10001`

错误处理（全模块统一走 `ai-i18n.handleAiError`）：
- 文案按 `utils/language.getSelectedLanguage()` 取对应语种（zh-Hans/zh-Hant/en/ja），`{hours}` 等占位替换
- 2xxxx 参数/违规 → toast（带「接口-」来源前缀，沿用项目 toast 约定）；22002/22003 封禁 → 弹窗+禁用聊天；3xxxx 上游错误 → 弹「重试」确认框（有重试回调时）；未知 code 降级 31001
- `detail` 是排障信息只打 console，**严禁展示给用户**（文档红线）

## 关键决策记录

- **小程序只能走非流式** `boltstaat-agent-fwdomalzks...fcapp.run`（wx.request 无 ReadableStream），流式 URL 仅存常量备 Web/Flutter 用
- **user_id 规则**：`boltfox_<用户userNo>`，未登录兜底 `boltfox_demo_user`（见 ai-api.getAiUserId；同一 user_id 多端历史互通）
- **独立接口层不复用 request.js**：第三方 FC 的 Base URL/响应结构/错误码体系与 BoltFox 后端完全不同，公共参数注入也不适用
- chat/enhance 超时 120s（生图上游可能 30s+），普通接口 15s，均不重试（生图 POST 重试有重复扣费风险）
