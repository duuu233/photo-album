## 设计要点（便于后续接手）

- **数值真值放 `this._edit`**（natW/natH、baseScale、baseW/baseH、frameW/frameH、zoom、tx、ty、angle），手势里不读 setData 后的异步 data；模板只绑定高频变化的 `editTransform` 一个串（`translate() rotate() scale()`）。
- **cover 基准**：`baseScale = max(frameW/natW, frameH/natH)`，zoom=1 时图片刚好铺满裁剪框（与未编辑图 `coverCropOne` 的 aspectFill 一致）。
- **预览↔导出一致**：预览用 CSS transform、导出用 canvas transform，两者用同一组 (tx,ty,angle,zoom) 与缩放系数 `k = 设备宽/裁剪框宽` 换算，像素级对齐。
