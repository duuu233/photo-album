# 2026-11-05 WiFi版轮播服务端化：时区、高级设置、保存后不再补投

> 分支：`main-wifi`｜依据：`docs/wifi/前端对接文档20261105.md`（轮播从「设备按 strategy 自己拉图」改为「服务端按配置定时推图」）；另按产品确认：开启轮播必须至少选一张图；下发轮播后设备会立刻自动刷屏，不需要再调 `/api/device/play`

## 做了什么

| 位置 | 改动 |
|---|---|
| 轮播设置 `wifi-slideshow` 普通视图 | 布局沿用原页面。新增「时区」行（默认手机时区，点开底部弹层分组列表 + 搜索，显示「Asia/Shanghai（UTC+8）」，只提交 IANA 名）；间隔档位改为 10 分钟 / 15 分钟 / 30 分钟 / 1~24 小时（去掉 1 / 5 分钟）；结束时间改两列选择器，可选 `24:00`；没配置过时起止默认 `00:00~24:00`；去掉「轮播后休眠」开关（`idle` 废弃，不再传）；轮播中显示「下次刷新：yyyy-MM-dd HH:mm」（`nextRefreshAt`）|
| 高级设置 | 照片卡片下方「高级设置 ▾」，同页展开 / 收起；进页一律收起、不持久化，有配置时按钮显示「高级设置（N 项）」。工作日 / 周末两张卡片带启用开关，纪念日可多条（日期选择只取月日，`02-29` 可选，重复日期拦截，可删除），卡片上标「当天独占」。每张卡片独立的时间（跟随上面的间隔 / 固定）、照片组（底部弹层选，同一套网格与顺序角标）、顺序 / 随机 |
| 提示 | 工作日 / 周末任一启用时，轮播方式下面灰字提示三档：只工作日「工作日已启用独立配置，本配置在工作日不生效」、只周末「周末已启用独立配置，本配置在周末不生效」、都启用「工作日与周末均已启用，本配置将不会生效」；纯文字不阻断保存 |
| 保存 | 带 `timeZone`；间隔 / 固定两组参数都带（当前模式的校验，另一方合法才带），切换模式不清空另一方；带 `weekday` / `weekend` / `anniversaries`。**基础配置和每张启用的卡片都至少选一张照片**，否则不让保存；卡片照片组一律明确提交 `imgUrls`（不省略）；不做跨卡片时间重叠校验。成功后**不再额外投第一张**，提示「已保存，…，屏幕即将刷新」，随后重新拉一次配置，时区 / 下次刷新 / 卡片以服务端回传为准（未保存的草稿丢弃） |
| WiFi 投屏结果页 `wifi-result` | 与蓝牙版一样两个按钮：全部成功「再投一张」+「返回首页」，有失败「重试未成功的」+「返回首页」（原「完成」去掉）。「再投一张」在当前页弹拍照 / 相册，选图后同一台设备进预览页 |
| 消息中心 | 新类型 `CAROUSEL_NOT_SENT`「轮播未发送成功」，内容「HH:mm 的轮播图片未发送成功，请检查设备网络状态」 |
| 配网 | 「设备正在连接云端」等待窗口 60 秒 → 120 秒 |

自行决定（可改）：

- 结果页成功按钮叫「再投一张」，失败仍是「重试未成功的」（多张时只重投没成功的）。
- 工作日 / 周末停用但选过照片的，带 `enabled:false` 和原参数提交（下次启用不用重填）；没选过照片的传 `null`。
- 卡片回显没有 `imgUrls` 时按全部相册全选（与基础配置同口径）。
- 开始与结束时间相同不让保存（「开始和结束时间不能相同」）。
- 手机时区：先取系统给的时区名，再取 `Intl`，都取不到按当前 UTC 偏移落到候选里同偏移的第一个，候选里没有用 `Etc/GMT±N`。
- `CAROUSEL_NOT_SENT` 的时刻字段对接文档没列，按 `time` / `triggerTime` / `scheduledAt` / `planTime` / `triggerAt` 依次取，取不到只显示后半句。
- 「下次刷新」只在轮播中显示。
