# 2026-11-02 WiFi版设备详情：设备ID、屏幕尺寸改为功能栏行

> 分支：`main-wifi`｜依据：产品要求（第 7、8 点：同蓝牙版详情样式）

## 做了什么

- 功能栏「设备信息」下新增「设备ID」行，再下面是「屏幕尺寸」行，左名右值、只展示不可点；值的字号颜色同蓝牙版详情（28rpx、`#777e88`）。
- 设备ID 取设备记录 `productDeviceId`，没有显示 `--`；屏幕尺寸取后台产品配置 `sizeModel`，没配整行不展示（同蓝牙版）。
- 顶部设备卡里电量上方的「屏幕尺寸 xx」一行去掉，改由上面的功能栏行显示。
- 同日追加：顶部设备名下的「设备ID xx」小字也去掉（与功能栏「设备ID」行重复）。
