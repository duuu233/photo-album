# 2026-11-14 WiFi 版点击入口要在线

> 分支：`main`｜依据：产品要求（WiFi 版投屏、轮播、固件升级、优雅刷新升级、TF卡切换点击时都要判断是否在线，不在线不能进；一键清空、删除设备、解绑设备不判断；蓝牙版不动）。

## 规则（`utils/wifi-status.js` 的 `requireOnline(device, knownStatus, { fresh })`）

- 页面已知状态为离线 / 休眠 / 关机 / 本地模式：直接给对应提示，不进。
- 已知在线：直接进。`fresh: true` 时仍现查一次。
- 查询中 / 状态未知 / `fresh`：现查一次 `GET /api/device/online`（loading「检查设备」），只有在线才进。查不到提示「设备不在线」。

## 接入位置

| 入口 | 页面 | 判断 |
|---|---|---|
| 投屏 | WiFi 详情、我的设备 WiFi 卡 | 按已知状态，未知现查 |
| 投屏（拍照 / 相册） | 首页（WiFi 版当前设备） | 现查（原「查不到放行」改为拦下） |
| 继续投屏 | WiFi 投屏结果页 | 现查 |
| 轮播设置 | WiFi 详情、我的设备 WiFi 卡 | 按已知状态，未知现查（原「离线也能看」撤掉） |
| 固件升级 | WiFi 详情 | 现查（升级页下发前仍会再判断） |
| 优雅刷新升级 | 设备信息页 | 现查 |
| TF卡切换 | TF 卡页开关 | 原本就是开启前现查、只放行在线，未改 |

一键清空、解除绑定、删除设备不判断在线。AI 生图 / 官方图库选设备投屏仍走 `ensureOnline`，预览页「开始投屏」本就严格判断，未改。
