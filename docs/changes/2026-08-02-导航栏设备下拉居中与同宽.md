# 导航栏设备下拉：与菜单同宽、整体居中、让开微信胶囊

> 日期：2026-08-02
> 范围：`components/page-nav`、`app.wxss`（设备照片页 / 投屏管理页共用）
> 双端同步：Flutter 见 `flutter/docs/history/2026-08/2026-08-02-导航栏设备下拉居中与同宽.md`
> 前置：`2026-08-01-交互与文案十一项优化.md` 第 3 / 10 项（下拉上移进导航栏）

## 问题（产品反馈）

1. 下拉按钮 370rpx、展开的菜单 420rpx，**两个宽度对不上**，展开时菜单比按钮宽出一截；
2. 整体要**居中**；
3. 小程序侧靠右排时右边缘正好压到微信自带的右上角胶囊，**要留间距**。

第 3 条不是「差一点」的问题：`page-nav` 的 `--nav-capsule-space` 就是
`windowWidth − menu.left`，而 `.nav-center` 原来写的是 `right: var(--nav-capsule-space)`
——右边界**正好落在胶囊左边缘上**，间距恒为 0，再加上按钮自带的投影，看着就是压着胶囊。

## 改动

| 位置 | 改动 |
| --- | --- |
| `components/page-nav/page-nav.wxss` `.nav-center` | 靠右 → **居中**：`left/right: 0` + `margin: 0 auto` + `max-width: var(--nav-center-max)`；自身 `pointer-events: none` |
| `components/page-nav/page-nav.js` | 新增 `computeCenterMaxWidth(windowWidth, capsuleSpace)`，`attached` 里算出 `centerMaxWidth` |
| `components/page-nav/page-nav.wxml` | 多传一个 `--nav-center-max` |
| `app.wxss` `.nav-device-filter` | 370rpx → **330rpx**；补 `pointer-events: auto` |
| `app.wxss` `.nav-device-filter__menu` | 去掉 `width: 420rpx / max-width: 70vw`，改 `left: 0; right: 0` = **与按钮同宽** |

### 为什么居中要用 `left/right: 0` + `margin: 0 auto`

绝对定位盒子左右都是 0、又有 max-width 时，`auto` 边距会把它摆到**屏幕正中**。
如果沿用「`right: 胶囊宽`」再 `justify-content: center`，中心点会被胶囊那一侧拽着左移，
看起来仍然是偏的。

### 为什么夹子（max-width）必须放在组件自己的节点上

页面通过 slot 传进来的 `.nav-device-filter` 属于**页面作用域**，组件样式管不到它；
反过来组件根节点上的 CSS 变量能沿渲染树继承下去。所以把 `max-width` 写在组件自己的
`.nav-center` 上最稳，`.nav-device-filter` 只需 `flex: 0 1 330rpx` + `min-width: 0`
就能跟着收窄。

### 为什么在 JS 里算宽度而不是写 `calc()`

胶囊宽度是 px 变量、页面尺寸是 rpx，混进 `calc()` 在部分基础库上会整条失效
（`.nav-center` 的 `left` 当年就为此写死 110rpx）。`computeCenterMaxWidth` 直接算：

```text
最大宽度 = 屏宽 − 2 × 胶囊占用宽 − 2 × 10px 间距   （下限 120px）
```

居中元素两侧各留 `(屏宽 − 自身宽)/2`，满足这条就右不碰胶囊、左不碰返回键
（返回键比胶囊窄，右边够了左边一定够）。

375pt 屏实测：胶囊占用约 94 → 上限约 171 > 330rpx(165)，所以维持 330rpx，
右边缘约 270、胶囊左边缘约 281，**间距约 11pt**。胶囊更宽/屏更窄的机型自动收窄。

### 为什么是 330rpx

370rpx 居中后右边缘约 277.5，离胶囊只剩 3~4pt，投影一糊还是像贴着。330rpx 是
「留得出 10pt 以上间距」与「设备名尽量少省略」之间的平衡值。

## 回归要点

- 两页（设备照片 / 投屏管理）按钮与展开菜单**同宽**、同左右边界；
- 下拉在屏幕水平方向居中，与胶囊有肉眼可见的间距；
- **返回键仍可点**（`.nav-center` 铺满整条但 `pointer-events: none`，只有下拉自己收点击）；
- 超长设备名单行省略号，不换行、不撑宽；
- 其余用 `title` 的页面（我的设备、设备详情等）导航栏无任何变化。
