# 2026-10-27 WiFi版休眠状态

> 分支：`main-wifi`｜依据：[休眠状态对接说明](../wifi/休眠状态对接说明.md) v1.0

## 做了什么

- `utils/wifi-status.js`：新增 `deviceState(info)`，认接口 / WS 的 `status`（`ONLINE` / `SLEEPING` / `OFFLINE`，大小写容错），缺 `status` 或不认识时按 `online` 回退；状态多一档 `sleeping`「休眠中」。新增 `blockedTip(status)`：休眠中 →「设备休眠中，唤醒后可操作」，离线 →「设备已离线，请检查设备网络」。`fetchFields` / `ensureOnline` 改用它们。
- 首页设备卡、我的设备 WiFi 卡、WiFi 设备详情页：显示「休眠中」，颜色蓝（`#2f80ed`），WiFi 图标同离线变淡；休眠中电量 / 信号同离线不显示。
- 投屏入口（首页拍照 / 相册、图库详情「连接并投屏」走 `ensureOnline`；我的设备卡、详情页「投屏」走 `blockedTip`）：休眠中直接提示「设备休眠中，唤醒后可操作」，不再提示检查网络。
- `utils/wifi-projection.js`：投屏接口回 4041 时补查一次 `GET /api/device/online`，`status=SLEEPING` 则失败文案改为「设备休眠中，唤醒后可操作」；补查失败或非休眠仍是离线文案；补查结果写进投屏日志。
- 详情页 WS `device.status` 照旧收到就重查，`SLEEPING` 推送随之显示。

## 没改的

- 配网第 4 步轮询仍只认 `online=true`，`SLEEPING` 不算成功（说明 4.3，原逻辑已满足）。
- 休眠设置（`POST /api/device/sleep`）属 STEP 5，页面未接；说明里「开始时间不能等于结束时间」留到接入时做。
- 不额外定时刷新状态，沿用进页面 / 「刷新状态」查询。
