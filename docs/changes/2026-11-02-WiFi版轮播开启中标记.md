# 2026-11-02 WiFi版「轮播设置」轮播开启中标记

> 分支：`main-wifi`｜依据：产品要求（轮播开启时在「轮播设置」上用图标辅助告知用户）

## 做了什么

- 我的设备 WiFi 卡、WiFi 设备详情的「轮播设置」：轮播开启中时，图标右上角显示绿点（带呼吸光圈），文字后加「轮播中」小标签；颜色同「轮播设置」（`#0e9f87`）。未开启不显示。
- 状态来源：`GET /api/device/strategy` 的 `running`（`wifi-status.fetchSlideshowRunning`，只要权限、离线也能查）。查不到（403 / 503 / 网络）保持原来的显示，不弹错。
- 刷新时机：列表每次 `onShow` 重拉时每台查一次，重拉期间沿用上次的标记不闪；详情每次进页查一次。从轮播设置页保存 / 暂停返回后即更新。
- 只做 WiFi 版；蓝牙版没有云端轮播状态，不加。
