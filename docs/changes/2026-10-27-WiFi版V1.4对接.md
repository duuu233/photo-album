# 2026-10-27 WiFi版 V1.4 对接 · 全页面联调日志浮窗

## 做了什么

### 投屏不再等 ack（更新说明第二节）

- `utils/wifi-projection.js` 重写：上传 → 图片处理中 → 接口返回即结束。`SENT`（旧版 `DOWNLOADING`）提示「已发送，屏幕即将刷新」；不再轮询 `/api/device/play/status`、不再等 WS `play.result`，也去掉了 TIMEOUT 修正窗口和 90 秒兜底。设备真正的成败由服务端写消息通知。
- 新增 `refresh`：`iot-api.play` 在 `refresh=false` 时带 `refresh=false`（默认不带，服务端默认 true），返回 `UPLOADED`、`msgid=null`。
- WiFi 投屏结果页：多张时本轮最后一张 `refresh=true`、前面的 `false`，整批只刷一次屏；重试未成功的也按「本轮最后一张刷屏」。`SENT` / `UPLOADED` 都算这一张成功。
- 4041 补查在线状态：`SHUTDOWN` 提示「设备已关机，开机后可操作」（原有 `SLEEPING` 不变）。

### 投屏写「我的上传」（更新说明 1.4 / 2.4 / 9.1）

- 相册数据由 App 调老服务维护：结果页每张拿到 `binUrl` 后调 `api.addWifiAlbumRecord`：`setFileUpload` 传这张图得到 `img` → `addUserProductImgRecord` 建记录（`img` + `imgBle=binUrl` + `deviceUploadState=1`，不带槽位）。
- 写记录失败不算投屏失败，这一张文案后注明「（未存入我的上传）」并记日志。

### 轮播设置（更新说明 1.5 / 第五节）

- 新页面 `subpackages/device/wifi-slideshow`（已注册）：
  - 回显 `GET /api/device/strategy`（离线也能查）；
  - 轮播方式：间隔时间（开始 / 结束 + 间隔档位 1 分钟～24 小时，按秒传 `timingTime`）/ 固定时间（每 1～365 天 + 若干时间点，去重排序，最多 24 个）；顺序 / 随机；轮播后休眠开关（`idle`）；
  - 轮播照片：从「我的上传」（这台设备的投屏成功记录，只取带 `imgBle` 的）单选 / 多选 / 全选，角标显示选择顺序，按顺序作为 `imgUrls` 提交（最多 200）；**一张不选就不带 `imgUrls`**（= 轮播全部照片），不提交空数组；回显 `imgUrls=[]` 或部分已删时给提示；
  - 「保存并开始轮播」`POST /api/device/strategy`，4041 补查给休眠 / 关机 / 离线提示；轮播中可「暂停轮播」（`POST /api/device/strategy/stop`）。
- 换算与选图顺序收在 `utils/wifi-strategy.js`。

### 页面按钮（更新说明 1.5）

- 我的设备 WiFi 卡：「刷新状态」→「轮播设置」（进上面的新页）；状态随进页 / 下拉刷新更新。
- WiFi 设备详情：「投屏」保留，「刷新状态」→「轮播设置」；状态随进页和 WS `device.status` 自动重查。
- 蓝牙版详情的「投屏 / 连接」与蓝牙轮播页未动（说明里的「设备内页」按 WiFi 版详情理解，见分析报告）。

### 删除照片（更新说明第九节）

- 「我的上传」选中的照片属于 WiFi 版设备时走单独链路，不连蓝牙、不认槽位：先删老服务记录 → 把真删掉的那些记录的 `imgBle` 交给 `POST /api/device/photo/delete`（每批 200），同时带 `nextImageUrl`（相册里剩下的第一张，删到屏上当前图时服务端自动换图）。
- 提示：全成功「已从相框播放列表移除，设备联网后更新」；`deviceNotified=false`「已删除；设备离线，相框换图将在设备联网后进行」；部分记录失败报张数；云端删除失败单独说。
- 「再次投屏」选中 WiFi 版照片：确认在线后带 `isWifi` 进预览页，导出后去 WiFi 投屏结果页。
- 蓝牙版照片的删除 / 再次投屏完全不变。`api.deleteProjectionRecords` 返回多一个 `failedIds`。

### 已关机状态（更新说明第三节）

- `utils/wifi-status.js` 认 `status=SHUTDOWN` →「已关机」（灰，同离线不显示电量 / 信号），入口提示「设备已关机，开机后可操作」。首页卡、我的设备卡、详情页共用。

### 全页面联调日志浮窗

- `utils/debug-log.js`：全局一份日志（最近 500 行，只在内存）；`app.js` 最先 `install()` 包装 `console`，已有的各类 `console` 日志不用改就能看到；token / 密码类字段入库前打码。
- `components/debug-log`：全局注册，35 个页面都放了 `<debug-log>`（`preview-demo` 复用 `preview` 模板）。左下角「日志 N」小药丸，点开日志框，可「复制 / 清空 / 关闭」；页面显示时记一行「页面 → 路由」。
- 网络层各记一行摘要：老服务 `[HTTP]`（路径不带公共 query）、IoT `[IoT]`、WebSocket `[WS]`（状态、收发，心跳不记）。
- 只在开发版 / 体验版生效；正式版不收集、不渲染、不包装 `console`。
