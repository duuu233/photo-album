# 2026-11-09 首页标签去图标、WiFi 详情一键清空与消息接口文案

> 分支：`main-wifi`｜依据：产品要求；消息部分按接口口径——`GET /api/notification/list` 新增选填 `lang`（`zh-CN` / `zh-TW` / `en` / `ja`，不传按简中），返回新增 `title` / `content`（服务端按 `lang` 翻译好，可直接展示），原参数不变

## 做了什么

1. **首页设备卡类型标签去掉图标**：「WiFi版·10.1寸 / 蓝牙版·1.69寸」标签前的 WiFi / 蓝牙小图标去掉（WiFi 卡下面的在线状态行本来就有 WiFi 图标，两个重复），标签左右内边距拉齐（`pages/home/home.wxml` / `home.wxss`，删 `.comm-badge__icon`）。状态行图标、搜索列表与选择设备弹层的角标不变。
2. **WiFi 详情隐藏「休眠设置」**：只去掉入口，`wifi-sleep` 页面、`openSleep` 方法与休眠状态显示都保留，恢复时把入口加回模板即可。
3. **WiFi 详情新增「一键清空」**（仅所有者）：
   - 布局样式照蓝牙版详情：「一键清空」（橙色扫把图标）+ 细分隔线 +「解除绑定」（红色图标）单独一张卡片（`.detail-list.action-list`，样式规则从蓝牙版 `detail.wxss` 搬过来），放在功能栏之下、页底「删除设备」之上；「解除绑定」因此从功能栏挪进这张卡片。接收者这张卡片只有「解除绑定」。
   - 两级确认同蓝牙版（「再想想 / 继续」→「我已阅读并了解此操作的结果，确认继续。」），一级文案改为「将清空该设备的云端照片并恢复设备内置图片，同时清空小程序/APP的图库」。
   - 执行的是「删除设备」的前三步，设备记录保留：① `clearUserProductImg` 清相册记录 → ② IoT `photo/delete all=true` 删全部云端照片 → ③ IoT `restore-builtin` 恢复内置图片。三步抽成详情页共用方法 `wipePhotos`，删除设备与一键清空同一套错误口径（①② 失败停下；③ 只有 `401` / `403` 停下，其余照常算完成）。成功提示「已清空」，并重查一次轮播标记。WiFi 版设备端不存图，不需要连蓝牙，离线也能清（恢复内置图片会被服务端 `SKIPPED`）。
4. **消息通知直接显示接口文案**：`iot-api.getNotifications` 新增 `lang`（有值才带）；消息中心列表与加载更多都带 `lang=zh-CN`（小程序默认中文，`utils/wifi-messages.js` 的 `NOTIFICATION_LANG`）。每条消息标题用接口 `title`、正文用接口 `content`（给了空串就不显示正文）；接口没给这两个字段时才用原来按 `type` / `payload` 拼的本地文案兜底。
