# 2026-11-05 WiFi配网去掉 2.4G 限制、搜索列表名称查询中显示 loading

> 分支：`main-wifi`｜依据：产品要求再次去掉 2.4G 配网限制（文字与过滤）；配网等设备入网 60 秒改 120 秒；搜索页名称先显示广播名再跳成用户设备名称，查回来之前给 loading

## 做了什么

| 位置 | 改动 |
|---|---|
| 选择 WiFi 页 `wifi-list` | 去掉顶部「设备仅支持 2.4G WiFi 配网」提示条（连同 `.wifi-tip` 样式），标题改回「设备附近的WiFi」，搜不到提示改「设备附近没有搜到WiFi，请重新搜索或手动输入WiFi名称」；设备扫描结果不再按信道只留 2.4G，5G、2.4G 都列出（同名仍取信号强的、按信号排序） |
| WiFi 账号密码页 `wifi-config` | 去掉同款提示条与样式，表单自己留上间距（`margin-top: 36rpx`） |
| 配网等设备入网 | 「设备正在连接云端」等待 120 秒（原 60 秒）——上一提交「WiFi版轮播服务端化」里已改，配网流程里没有别的 60 秒超时，本次不再改动 |
| 搜索设备页 `bind` | 用户设备名称（`getBoundDeviceNames`）查回来之前，列表名称处显示小圆圈 loading（占一行名称高度，切换时行高不变），查回来后一次性显示「用户名称 / 广播名」，不再先显示广播名再跳；最多等 5 秒，超时先显示广播名，结果晚到仍补上；名称先于扫描结果回来时直接结束 loading |

`utils/blufi.js` 的 `is24GChannel` / 信道解析保留（协议解析与测试仍在用），只是列表页不再拿它过滤。
