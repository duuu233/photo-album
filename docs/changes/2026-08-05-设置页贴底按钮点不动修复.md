# 2026-08-05 设置类页面贴底按钮「看得见、点不动」修复（退出登录 / 用户注销）

> 状态：**小程序端已实现**，**未真机验收**
> 最后核对：2026-08-05
> 适用范围：微信小程序（Flutter 侧核对后无此问题，见文末「Flutter 侧核对」）
> 权威来源：本次问题反馈、当前源码
> 取代/被取代：修正 [2026-08-05 我的相册计数与全站折叠屏适配](2026-08-05-我的相册计数与全站折叠屏适配.md)
> 中「贴底按钮一律留在滚动区外」那条做法的**遗漏**（结构结论不变，补上层级要求）

## 现象

进「我的 → 设置」，**「退出登录」和「用户注销」点不动**：按钮画得好好的、位置也没错，
按下去既没有 hover 态也不弹确认框。**与是不是折叠屏无关**，普通手机上就能复现。

## 根因：透明的滚动区盖在按钮上面，把点击吃掉了

2026-08-05 那轮折叠屏适配把设置类页面改成了「模式 B · 容器滚动」：

```text
.settings-shell.fold-viewport   ← 一屏高，flex 纵向
  page-nav                       导航栏
  .mock-bg                       固定背景层（z-index: 0）
  scroll-view.fold-scroll        ← flex: 1 1 0，从导航栏一直铺到根容器底部
  .outline-logout / .delete-account   ← position: absolute; bottom: …（贴根容器底部）
```

`.fold-scroll` 带着 `z-index: 1`（为了盖住 `z-index: 0` 的 `.mock-bg`），
而两枚贴底按钮**没写 z-index**（`auto`）。层叠顺序里 `auto` 属于 0 层、`1` 在其上，
**DOM 顺序在后也压不过更高的 z-index**——于是滚动区整块盖在按钮上面。

滚动区是透明的，所以：

- **看**：按钮照常显示，位置一像素没变（它们的定位父级仍是根容器）；
- **点**：命中测试打在最上层的 `scroll-view` 上，事件被它吃掉，`bindtap` 永远不触发。

滚动区从导航栏铺到根容器底部，正好覆盖这摞按钮所在的区域，所以**内容装不装得下都点不动**。

## 改法：留在滚动区外的可点元素显式抬到 z-index 2

结构不动（按钮仍留在滚动区外、定位父级仍是根容器，位置逐像素不变），只补层级：

| 文件 | 元素 | 改动 |
| --- | --- | --- |
| `subpackages/settings/index/index.wxss` | `.outline-logout`（退出登录）、`.delete-account`（用户注销） | **补 `z-index: 2`**（原来缺省，被滚动区盖住 → 本次故障） |
| `subpackages/settings/update/update.wxss` | `.delete-account`（用户注销） | **补 `z-index: 2`**（同上，同款故障） |
| `subpackages/settings/update/update.wxss` | `.update-btn`（立即更新） | 显式写 `z-index: 2`（原先靠 `.primary-btn` 的 `z-index: 1` + DOM 在后侥幸压住） |
| `subpackages/settings/language/language.wxss` | `.save-language`（保存设置） | 同上，显式写死 |
| `subpackages/settings/form.wxss` | `.form-submit`（忘记密码页「确认」） | 同上，显式写死 |
| `styles/fold-adapt.wxss` | `.fold-scroll` 注释 | 加⚠️告警：**留在滚动区外又与滚动区重叠的元素必须 `z-index ≥ 2`** |

「同层 z-index 靠 DOM 顺序压住」是侥幸，不作为方案：`.primary-btn` 的 `z-index: 1` 与
`.fold-scroll` 同层，一旦有人调整节点顺序就会复现同款故障，所以四枚按钮统一写死 2。

`profile` / `bind-email` / `change-email` 三页的提交按钮是 `position: fixed` 且**在滚动区内**、
本就带 `z-index: 2`，不受影响；`projection/result` 的底部按钮组是滚动区的**兄弟流式块**
（不与滚动区重叠），也不受影响。

## Affected Areas

- `subpackages/settings/index/index.wxss`、`update/update.wxss`、`language/language.wxss`、`form.wxss`
- `styles/fold-adapt.wxss`（注释与告警）
- `AI_CONTEXT.md`（折叠屏方案那条规则补一句层级要求）

## Flutter 侧核对（无需改动）

`lib/src/features/settings/presentation/settings_page.dart` 用 `FigmaScreen(bottom: …)`：
「退出登录」胶囊与「用户注销」文字链在 `Column` 的 `bottom` 槽位里，与滚动区是**上下排布的兄弟**，
不存在重叠，也就没有层级遮挡；两者的 `onTap`（`_confirmLogout` / `_confirmDeleteAccount`）
在任何窗口高度下都可点。Flutter 没有 z-index 概念，重叠只会出现在 `Stack` 里，本页不涉及。

## Risks

- 本轮只改层级，不改位置与结构，理论上不影响观感；仍建议真机点一遍
  设置 / 语种设置 / 更新 / 忘记密码四页的贴底按钮。
- 折叠屏展开态下这些按钮仍以根容器（一屏高）为定位父级，位置与竖屏一致；
  内容变长时从按钮下方滚过去的观感由 `.settings-scroll-body` 的 `padding-bottom` 兜着，未变。
