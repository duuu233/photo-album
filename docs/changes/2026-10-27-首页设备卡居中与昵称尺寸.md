# 2026-10-27 首页设备卡：内容居中、默认昵称取完整广播名、显示尺寸

> 分支：`main-wifi`；修改前：f336637。背景：真机反馈首页设备卡蓝牙版 / WiFi 版内容整体偏左；绑定后的设备名不是完整蓝牙广播名（WiFi 版传的是产品名）；首页看不到尺寸。

## 改动

- 版式（`pages/home/home.wxss`）：`.device-carousel` 由 `space-around` 改为 `justify-content: center` + `gap: 44rpx` + 左右内边距 40rpx。原写法把空白按内容宽度分摊——名称长时设备图贴左、名称短时图文被拉开，两类卡看着都偏左。设备图 `flex: 0 0 auto` 不被挤小；文字区 `min-width: 0`，名称上限 320 → 364rpx（卡内可用宽 574 − 图 166 − 间距 44），完整广播名如 `IJ_E348C21ED428` 基本放得下，再长仍省略号。
- 默认昵称 = 完整蓝牙广播名：
  - `utils/broadcast-match.js` 新增 `fullBroadcastName`：`name` / `localName` 去空白后取较长的那个（真机上两者常只有一个带全），都没有返回空串。
  - 蓝牙版（`subpackages/device/bind/bind.js`）：绑定 payload 的 `name` 改取 `fullBroadcastName(scanDevice)`，取不到回落原 `scanDevice.name`；`api.bindDevice` 仍以它作 `addUserProduct.productName`，后端回带旧昵称时仍以后端为准（2026-08-12 口径不变）。
  - WiFi 版：配网交接与路由的 `name` 取完整广播名；`api.bindWifiDevice` 的 `productName` 改为广播名优先、取不到才回落产品名（原来产品名优先，同款 WiFi 设备绑定后全叫一个名字）。已绑定过的设备走复用分支，名字不变。
- 尺寸：首页 `normalizeDevice` 透传 `sizeModel`（设备列表接口下发）；名称下方加类型 + 尺寸标签「WiFi版·5.89寸 / 蓝牙版·5.89寸」，样式同搜索列表 `.comm-badge`，没配显示「--寸」。标签占位后文字区最小高度 220 → 256rpx、名称下边距 18 → 12rpx，卡片高度不变。
