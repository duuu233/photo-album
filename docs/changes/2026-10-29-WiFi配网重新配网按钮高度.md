# 2026-10-29 WiFi版配网失败「重新配网」按钮高度修复

> 分支：`main-wifi`

## 做了什么

- 设备配网页（`subpackages/device/wifi-provision`）失败态的「重新配网」按钮高度不对。原因：失败态按钮区是上下排（`flex-direction: column`），主按钮 `.provision-primary` 沿用成功态横排用的 `flex: 1`，在列方向上 `flex-basis` 顶掉了 `height: 112rpx`。
- 只在上下排里改为 `flex: none`，按钮恢复 112rpx 高，与 WiFi 投屏结果页的主按钮一致；成功态「立即体验」不受影响。
