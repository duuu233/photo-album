# 2026-11-14 首页设备卡：设备图与文字上下居中

> 分支：`main`｜依据：用户反馈首页设备轮播卡内容没有垂直居中（如 WiFi 版 13.3 寸设备），要求参照 APP。

- 原因：
  - 右侧文字块固定了 `min-height: 256rpx`（为了蓝牙卡切换连接态时文字不跳），内容从顶部排。WiFi 卡只有名称、类型标签、状态三行，被顶在上半截，和左侧设备图对不齐；
  - 设备图用 `aspectFill`，非方图（如 13.3 寸）被裁切、看着偏。
- 改法（同 APP `_ConnectedDeviceCard`）：
  - 去掉 `.device-info` 的 `min-height`，文字块按内容高度与设备图一起在卡片里上下居中；
  - 图文整体仍水平居中、间距 44rpx 不变；
  - 设备图改 `aspectFit` 完整显示；
  - 蓝牙卡有无「连接蓝牙」按钮时各自重新居中，与 APP 一致。
