# 2026-11-02 投屏进度页显示出帧地址（调试）

> 分支：`main`（同步 `main-wifi`）｜依据：联调需要，把出帧时实际拿到的地址显示在页面上

## 做了什么

- `utils/dithering.js` 记下最近一次取出帧地址的情况，`getLastEndpoint()` 返回：
  - 来源：接口下发（`download-endpoint` 返回有效地址）/ 缓存（10 分钟内复用）/ 取不到，回落默认（`https://api.boltfox.cn`）；
  - 基地址、请求地址（基地址 + `/Client/Basic/imageDitheringBinDownload`，**不带公共参数，不含 userToken**）；
  - 返回概要：`HTTP 状态 code=… data=…`，或网络失败原因。
- 蓝牙投屏进度页（`subpackages/projection/result`）每张图出帧后（成功失败都算）在说明文字下方显示一个虚线框：来源、基地址、请求地址、返回；点一下复制全部内容。
- **只在开发版 / 体验版显示**，正式版及取不到环境信息时不显示。
