# 2026-11-06「选择投屏设备」弹层蓝牙版标识

> 分支：`main-wifi`

## 做了什么

- 「选择投屏设备」弹层（`components/device-picker-sheet`）里，蓝牙版设备在名称后挂「蓝牙版」角标：蓝牙图标（`badge-bluetooth.svg`）+ 蓝色浅底描边，与搜索列表的蓝牙版标签同款配色。WiFi 版仍挂原来的「WiFi版」角标，两者二选一，按调用方给的 `isWifi` 区分。
- 角标样式拆成基础规则 `.picker-device__badge`（尺寸、圆角）+ 颜色修饰 `--wifi` / `--ble`；WiFi 版观感不变。
- 弹层是图片详情页与 AI 对话页共用的组件，两处同时生效；两处本来就给每行带了 `isWifi`，调用方未改。
