# 2026-11-12 首页设备卡进「我的设备」默认停在对应 Tab

> 分支：`main`｜依据：产品反馈：首页点的是蓝牙版设备卡，跳到设备列表要默认显示蓝牙版 Tab，WiFi 版同理

## 原因

首页设备卡（`goDeviceList`）跳设备列表不带任何参数，列表页按 2026-11-06 的默认规则选 Tab：普通模式 WiFi版在前，只有 WiFi 版没有设备时才落到蓝牙版。所以两类设备都有时，从蓝牙版卡进来也停在 WiFi版。

## 做了什么

| 位置 | 改动 |
|---|---|
| 首页设备卡 `pages/home/home.wxml` | `.device-carousel` 加 `data-tab`：WiFi 版卡 `wifi`、蓝牙版卡 `ble` |
| `pages/home/home.js` `goDeviceList` | 从卡片进来带 `?tab=wifi / ble`；六宫格「我的设备」也走这里但不带事件，仍是不带参数的地址 |
| 设备列表 `subpackages/device/list/list.js` `onLoad` | 认 `options.tab`（只认 `wifi` / `ble`）：设为当前 Tab，并按「用户选过」处理（`deviceTabChosen`），之后 onShow 重拉列表不被默认规则改掉；该类没有设备时显示该 Tab 的空态（默认设备图 + 加号）。选相框模式（`select=1`，只能选蓝牙版）不认 `tab` |

其他入口（我的页「我的设备」、设备详情返回列表、六宫格）不带参数，默认规则不变。

## 涉及文件

`pages/home/home.wxml`、`pages/home/home.js`、`subpackages/device/list/list.js`、`tests/device-list-wifi-group.test.js`。

## 验证
