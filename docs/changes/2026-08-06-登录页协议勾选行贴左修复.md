# 2026-08-06 登录页协议勾选行贴左修复（`align-self` 在块级父容器里失效）

> 状态：**小程序端已实现**，**未真机验收**
> 最后核对：2026-08-06
> 适用范围：微信小程序（登录页；Flutter 侧不涉及，见文末）
> 权威来源：本次问题反馈、当前源码
> 取代/被取代：修正 [2026-08-05 我的相册计数与全站折叠屏适配](2026-08-05-我的相册计数与全站折叠屏适配.md)
> 给登录页套壳时的**遗漏**（折叠屏结构结论不变，补一条「居中方式」要求）

## 现象

登录页最下面那行「☐ 我已阅读并同意《用户协议》和《隐私政策》」**整体贴到了左边**，
不再与上方 logo、「微信登录」按钮同一条中轴线。

**与是不是折叠屏无关**：普通直板手机上一样偏——折叠屏适配那轮改的是所有机型都会走的 DOM 结构，
不是加在某个媒体查询里的分支。

## 根因：父容器从 flex 变成块级，`align-self` 直接失效

`.login-agreement` 的水平居中原先只写了 `align-self: center`，它成立的前提是
**父节点是 flex 容器**。2026-08-05 那轮折叠屏适配把登录页改成「模式 B · 容器滚动」，
内容整体搬进了滚动区：

```text
改动前                                改动后
.login-page(display:flex; column)     .login-page.fold-viewport(display:flex; column)
  .login-main                           page-nav
  .login-agreement  ← flex 项，          scroll-view.fold-scroll
    align-self 生效                        .fold-scroll-body   ← 普通块级（无 display:flex）
                                             .login-main
                                             .login-agreement  ← 现在是块级子元素，
                                                                 align-self 被忽略
```

`.fold-scroll-body` 只有 `position/box-sizing/min-height`，**没有 `display: flex`**，
所以对它的子元素来说 `align-self` 是一条无效声明。而这一行同时写着
`width: 100%; max-width: 600rpx`——宽度被压到 600rpx、又没有任何居中约束，
块级元素默认靠左，于是整行贴左。

同页 `.login-main` 不受影响：它自身占满宽度，内部靠 `align-items: center` 给
logo 和按钮居中，父容器是不是 flex 与它无关。这也是「只有协议行偏了」的原因。

## 改法：居中改用 `margin: … auto`

| 文件 | 元素 | 改动 |
| --- | --- | --- |
| `pages/login/login.wxss` | `.login-agreement` | 删掉失效的 `align-self: center`，`margin-top: 58rpx` 改为 `margin: 58rpx auto 0`；上边距不变 |

`margin: … auto` 在块级父容器和 flex 父容器下都能居中，**不再依赖父节点的 display**，
以后再被搬进/搬出滚动容器也不会重演。结构、层级、间距一律不动。

## 同类隐患排查（本次无其它需要改的）

全仓 `align-self` 只在四处出现，逐个核对过父容器：

| 位置 | 父容器 | 结论 |
| --- | --- | --- |
| `pages/login/login.wxss` `.login-agreement` | `.fold-scroll-body`（块级） | **本次故障，已修** |
| `pages/home/home.wxss` `.carousel-dots` / `.empty-hero-art` / `.bind-pill` | `.home-content`（`display:flex; column`） | 仍生效，不动 |
| `subpackages/projection/preview/preview.wxss` `.carousel-dots` | `.preview-page`（`display:flex; column`） | 预览页按方案**不套滚动容器**，父容器仍是 flex，不动 |
| `subpackages/ai/chat/chat.wxss` `align-self: flex-start` | 消息气泡的 flex 父容器 | 与折叠屏改动无关 |

另外核对了其余套了 `.fold-scroll-body` 的页面（`projection/result`、`settings/index`、
`settings/update`、`settings/language`、`settings/forgot-password`）：
它们的根类要么本就不是 flex（`.settings-shell`），要么虽是 flex 但没设置横向居中
（`.result-page` 是默认 `align-items: stretch`，子块本来就占满宽度），
搬进块级容器后子块同样占满宽度，观感不变。

## Affected Areas

- `pages/login/login.wxss`（`.login-agreement` 居中方式）
- `AI_CONTEXT.md`（折叠屏公共方案那条规则补一句：套壳后 `align-self` 居中会失效）

## Flutter 侧核对（不涉及）

Flutter 登录页的协议行在 `Row(mainAxisAlignment: center)` 里，居中由 Row 自己决定，
不存在「父容器换了 display 导致对齐声明失效」这类 CSS 特有问题；本次无需同步。

## Risks

- 只改水平居中方式，垂直间距（58rpx）与点击热区（`.login-agreement__check-group`
  的负 margin 抵消，见 login.wxss 注释）都没动，理论上不影响勾选手感。
- 折叠屏展开态下这一行仍是 600rpx 上限居中，屏越宽两侧留白越大，与竖屏观感一致。
