# 星币套餐卡赠送角标位置统一与卡片收窄

> 状态：Historical
> 日期：2026-09-08
> 环境：SSH 开发机
> 分支与起始版本：main / 0b1a7b3
> 范围：小程序星币管理页面的套餐卡

## 变更

### 1. 赠送角标：选中与未选中位置一致

原来两种状态画在两个位置：未选中是卡片内右对齐的橙色文字，选中才变成实心橙标签浮到卡片右上角，
点选时角标会跳一下。现在 `.package-gift` 基础样式直接带上 `position: absolute; top/right: -3rpx`
与圆角、内边距，两种状态几何完全相同，`.package-card--active .package-gift` 只覆盖
`color` 与 `background`：未选中是透明底橙字，选中是橙底白字。

⚠️ `.package-gift-slot` 那 32rpx 占位**更不能删**：角标现在恒为 `absolute`、任何状态下都不占高，
而卡片是 `justify-content: center`，占位一旦没了，有赠送和无赠送的卡片内容会差半格。

### 2. 卡片收窄，右侧留白变少

**当日收窄三次**：`.package-card` 宽度 300rpx → 276rpx → 248rpx → **208rpx**
（`flex-basis` 同步），左右内边距 22rpx → 20rpx → **16rpx**。

⚠️ **根因是上一轮把需求读错了**：「价格最少支持六位数值展示」当时被理解成六位**整数**
（`￥999999.99`），因此把卡片从设计稿的 200rpx 加宽到 300rpx、并把主价格字号从 48rpx 降到
40rpx。产品本轮澄清：**六位是连小数点后两位一起算，整数部分四位就够，即最大 `￥9999.99`**。
那次加宽与降字号本来都不必要，前两次收窄也是在这个错误余量上打转。

现在内宽 208 − 16×2 = 176rpx，`￥9999.99` 在 40rpx 字号下约 157rpx，留约 19rpx 余量。

⚠️ **主价格字号仍是 40rpx，没有跟着改回 48rpx**：改回去的话 `￥9999.99` 约需 183rpx，
卡片得退回 216rpx 以上。「窄卡片」和「设计稿字号」二选一，本轮按产品反复要求的方向保窄卡片；
要换回 48rpx 需一并放宽卡片宽度。
