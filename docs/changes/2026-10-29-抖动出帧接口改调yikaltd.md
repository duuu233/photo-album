# 2026-10-29 抖动出帧接口改调 api.yikaltd.com

> 分支：`main`（`main-wifi` 经合入 main 同步）｜依据：产品口径——投屏抖动出帧接口地址改为 `https://api.yikaltd.com/api/Client/Basic/imageDitheringBinDownload`，参数全部不变

## 做了什么

- `utils/dithering.js`：抖动出帧请求由 `https://api.boltfox.cn/Client/Basic/imageDitheringBinDownload` 改为 `https://api.yikaltd.com/api/Client/Basic/imageDitheringBinDownload`。
- 参数不变：公共参数 device / terminal / language / userToken（query + header）、鉴权头、form-data 字段 `color=BWRYGB` / `imageDitheringModes=2` / `type` / `file`、二进制响应解析、业务报错与 401/406 登出、网络失败重试 3 次，全部照旧。
- `utils/request.js`：`clientRequestParts` 新增可选第三个参数 `{ baseURL }`，只换掉默认的 `config.baseURL`；不直接传绝对地址，是因为公共参数只对 `/Client/` 相对路径拼接，传绝对地址会把它们丢掉。其它接口不受影响。
- ⚠️ 小程序后台「request 合法域名」需要加 `https://api.yikaltd.com`，否则真机请求会被拦截（开发者工具勾选不校验域名时看不出来）。
