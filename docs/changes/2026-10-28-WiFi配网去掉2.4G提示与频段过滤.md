# 2026-10-28 WiFi 配网去掉 2.4G 提示与频段过滤

> 分支：`main-wifi`；修改前：2ea6572。
> 已于 2026-10-29 撤回，见 [WiFi配网恢复2.4G提示与频段过滤](2026-10-29-WiFi配网恢复2.4G提示与频段过滤.md)。

## 背景

10-27 已去掉选择 WiFi 页的「设备仅支持 2.4G WiFi 配网」提示条与标题里的 2.4G，账号密码页的同款提示和搜不到时的提示当时未动。产品口径：关于「设备仅支持 2.4G WiFi 配网」的文案全部删除；WiFi 列表也不再按频段过滤，5G、2.4G 都显示。

## 改动

- `subpackages/device/wifi-config`：删掉表单上方的提示条「设备仅支持 2.4G WiFi 配网」及 `.wifi-tip` / `.wifi-tip__icon` 样式；原提示条承担的表单上方间距改由 `.wifi-form` 的 `margin-top: 36rpx` 留出。
- `subpackages/device/wifi-list/wifi-list.js`：
  - `toWifiList` 去掉按信道只留 2.4G 的过滤，设备回的 5G、2.4G 都列出；隐藏网络不列、同名取信号强的、按信号排序不变。
  - 搜不到时的提示「设备附近没有搜到2.4G WiFi…」改为「设备附近没有搜到WiFi，请重新搜索或手动输入WiFi名称」；控制台日志去掉「2.4G」。
- `utils/blufi.js` 未改：解析出的 `channel` / `frequency` 与 `is24GChannel` 保留，页面不再用来过滤。
- `tests/wifi-search.test.js`：分批用例改为 5G、2.4G 都列出并按信号排序；新增设备回空列表时提示不含 2.4G；断言账号密码页模板与样式不再有 2.4G 提示与 `.wifi-tip`；列表页桩去掉不再用到的 `is24GChannel`。

## 注意

- [设备入网流程](../wifi/设备入网流程.md) 仍写「设备只支持 2.4GHz WiFi … App 需提示仅支持 2.4G」，与本次口径不一致；本设备实测回包含 5G 信道（双频芯片），选 5G 网络能否配网成功需真机确认。
