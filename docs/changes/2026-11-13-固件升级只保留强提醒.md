# 2026-11-13 固件升级：去掉强制升级，只保留强提醒 / 弱提示

> 分支：`main`｜依据：产品改口（去掉强制升级逻辑，首页、列表页、详情页都不要；只保留强提醒升级与弱提示升级）。取代同日 [固件强制升级 / 强提醒升级判断](2026-11-13-固件强制升级与强提醒升级判断.md) 与 [按升级类型与本地缓存](2026-11-13-固件升级判断按升级类型与本地缓存.md) 中的强制升级部分。

## 升级类型

| `updateType`（后台 `compulsory`） | 红点 | 进入设备详情页 |
|---|---|---|
| 2 强提示升级（强提醒） | 亮，用户主动点 | 弹提示框 |
| 3 弱提示升级 | 亮，用户主动点 | 不弹 |
| 4 不提示升级 / 没给 | 照旧按版本亮 | 不弹 |
| 1 原强制升级 | 亮 | 后台已隐藏该选项，存量数据按强提醒弹 |

## 强提醒

- 只在进入设备详情页（`detail` / `wifi-detail`）时判断一次：WiFi 版在线、蓝牙版已连接，且「固件升级」红点亮才弹。
- 弹框「立即升级 / 取消」：立即升级进升级页（蓝牙 `ota?auto=1`，WiFi `wifi-ota`）；取消后本次启动不再弹这台，关闭 / 重启小程序后再进入才再弹（`firmwareGate.checkOnEnter`，内存记录，按设备计）。

## 去掉的部分

- 详情页功能按钮不再判断（撤掉 `wrapActions` / 页面 `firmwareGate()`），投屏连上后直接弹拍照 / 相册。
- 设备列表页投屏 / WiFi 轮播设置、首页拍照 / 相册投屏不再判断：撤掉 `guardAction` 的 loading 现查与本地缓存 `fw_gate_cache`。
- 升级完成不再更新缓存（`ota` / `wifi-ota` 撤掉 `markUpgraded`）。
