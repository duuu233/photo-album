## 1. 解除绑定后再次添加，带出后端回带的昵称

**后端本轮改动**：`POST /Client/UserProduct/addUserProduct` 的出参
（`ClientUserProductDetailApiOut.productName`）在**重新绑定一台曾经解绑过的设备**时，
会把它上次保存的名字原样带回来。绑定成功后的命名弹窗要带出这个名字，而不是又给一个默认名。

端上原来这么写（`utils/api.bindDevice`）：

```js
const saved = await addUserProduct(payload)
return normalizeDevice(Object.assign({}, scan, saved, { …, productName }))
//                                                          ↑ 本地拼的默认名盖在最后
```

两处都得改，少一处都不生效：

- `productName` 本地值**盖在 `saved` 后面** —— 后端给什么都被覆盖掉；
- 就算只改 `productName` 也还是不够：`normalizeDevice` 的 `name` 取「第一个非空」，
  而 **`scan.name`（蓝牙广播名）排在 `productName` 前面** —— 弹窗读的是 `name`，
  带出来的仍会是「BoltStar-D428」这种广播名。

现在：后端回带了名字就连 `name` 一起以它为准；没回带（首次绑定 / 老后端）保持原取值链不变。
首次绑定本来就不受影响 —— 那时后端回的就是我们刚提交上去的 `productName`。
由 `tests/rebind-name-and-ai-config.test.js` 锁住这两条。

## 2. AI 助手页「未绑定设备」提示改自绘

`checkDeviceBound()` 的 `wx.showModal` → 页面自绘 `.confirm-mask` / `.confirm-dialog`
（与删除确认框、星币不足弹窗同一套版式，icon 用 `ai-project.png` 那块屏）。

⚠️ 这个弹窗的遮罩**不做「点外面关闭」**（与另外两个不同）：它是「去绑定 / 返回」的二选一，
点空白处溜走只会把用户留在一个投不了屏的页面上，还以为是自己点错了。
两颗按钮的行为与原生弹窗一致：`返回` = 退回上一页（走本页的 `goBack`），`去绑定` = 进绑定页。

## 3. 会话列表的星币胶囊加 `>`，点击进星币管理

整颗胶囊可点，右端补一个 `.ui-chevron`（app.wxss 里的公共箭头，border 拼的，不引图片）。
余额看着不够时用户在这一页就能直接去买，不用退回「我的」再找入口；
买完退回本页 `onShow` 会重取余额，数字自动对上。

## 4. 星币管理页新增「星币消耗规则」

接口：`GET /Client/Order/getAiConfigList`，`retData` 是**裸数组**（不是分页壳），
每项 `ClientAiConfigApiOut`：

| 字段 | 含义 | 页面列 |
| --- | --- | --- |
| `aiProject` | ai 项目 | 服务类型 |
| `num` | 消耗 token 数量（**number**） | 星币消耗（星币/次） |
| `remark` | 备注 | 说明 |

> ⚠️ **2026-08-13 表格已改**：表头收成「星币/次」、**「说明」整列去掉**，页面只剩两列
> （`remark` 仍照常映射，只是不画）——见
> [2026-08-13 那篇第 4 条](2026-08-13-OTA连接硬复位与AI入口续聊.md)。下面按当时口径记录。

另有 `aiConfigId`（wx:key 用）、`aiModel`(1=普通 2=专家 3=会话条件)、`aiModelMsg`，页面暂不用。

渲染在「购买 & 消费记录」那一栏下面，卡片底与它同款（这一页只保留一种卡片观感）。

- **顺序原样保留**：后端按 `grade`（权重）排好再下发，而 Client 出参里没有这个字段，
  端上重排只会和后台配置对不上。「最低账户余额 30 发起会话条件」那条也在这个列表里
  （`aiModel=3`），不做特殊处理 —— 它就是规则表的第一行。
- `num` 是 number：`30.0` 要显示成 `30`（星币是整数计价，小数点只会让人以为还有小数位），
  真有小数最多留两位。
- **静默失败**：拉不到就整块不渲染（`wx:if="{{aiConfigs.length}}"`），不弹红字也不留空白 ——
  它是说明性内容，挂了不该盖住「买星币」这件正事。每次 `onShow` 重拉（后台随时可能改价）。
- 没有 `aiProject` 的脏数据不进表：画出来就是一行空白。

表格是 flex 手搭的三列（36% / 26% / 剩余）。⚠️ **行高不能写死**：表头「星币消耗（星币/次）」
和「图生图 / 融合图-1」这类长服务类型都会折行，写死高度就会把字裁掉。

## Risks

- 「后端回带昵称」这条**依赖后端已上线**：老后端不回 `productName` 时端上自动回落到原行为，
  不会报错，但也就看不到新表现 —— 验收时要确认后端已发布。
- 规则表的文案（服务类型 / 说明）**全部由后台配置**，端上一个字都不写死。
  后台改了措辞或加了新档位，页面自动跟着变；反过来，后台没配就整块不显示。
- `aiModel=3`（会话条件）与其它档混在同一个列表里，端上不区分。
  若产品后续要把「最低账户余额」单独拎出来强调，需要按 `aiModel` 分组，届时再改。
