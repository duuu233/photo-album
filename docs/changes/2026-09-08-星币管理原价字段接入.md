# 星币管理原价字段接入

> 状态：Historical
> 日期：2026-09-08
> 环境：SSH 开发机
> 分支与起始版本：main / 96e4d2a（本轮提交 834c9d7）
> 范围：小程序星币管理页面套餐卡的划线原价与币种符号

## 变更

套餐卡的划线金额由上一轮的静态 `￥0.01` 改为取接口下发的原价。`utils/token-api.js` 的 `normalizePackage` 新增 `marketAmount` 与 `currencySymbol` 两个字段，页面 `loadPackages` 据此拼 `referencePriceText`，两位小数、沿用原有删除线与灰色样式。原价**只用于展示，不参与下单金额与支付计算**。

取值口径（`marketAmountOf`）：

- 按当前语种取字段，语种码 0/1 英文、2 简中、3 繁中、4 日文，对应 `marketAmountEnglish` / `marketAmount` / `marketAmountFan` / `marketAmountJapanese`；语种专属字段不存在时回落 `marketAmount`，兼容服务端已按语种投影的响应。
- 语种专属字段存在但为空时**不跨语种回退**，避免把别的币种金额贴到当前语种上。
- `0` 是有效金额照常展示；缺失、空串、负数、非有限数一律为 `null`，页面留空行不显示虚构金额。
- 主价格的货币符号也改取商品的 `currencySymbol`，后端没给才回落 `¥`；符号与金额必须同源，端上不再写死。

`.package-unit` 增加 `min-height: 22rpx`：没有原价时该行仍占位，卡片高度不随有无原价跳变。
