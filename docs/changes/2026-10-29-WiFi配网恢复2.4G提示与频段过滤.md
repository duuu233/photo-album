# 2026-10-29 WiFi 配网恢复 2.4G 提示与频段过滤

> 分支：`main-wifi`；修改前：0d1bc5f。撤回 [10-28](2026-10-28-WiFi配网去掉2.4G提示与频段过滤.md) 与 10-27「选择WiFi页去掉2.4G字样」两次改动。

## 背景

产品口径改回：WiFi 版设备只支持 2.4G，配网相关提示都写明只支持 2.4G。蓝牙版不涉及。与 [设备入网流程](../wifi/设备入网流程.md)「设备只支持 2.4GHz WiFi … App 需提示仅支持 2.4G」一致。

## 改动

- `subpackages/device/wifi-list`（选择 WiFi 页）：
  - 顶部恢复提示条「设备仅支持 2.4G WiFi 配网」及 `.wifi-tip` / `.wifi-tip__icon` 样式，灰字手动输入入口仍在提示条下方；
  - 列表标题恢复「设备附近的2.4G WiFi」；
  - `toWifiList` 恢复按信道只留 2.4G（ch 1~14），5G 去掉；设备没回信道（乐鑫标准格式）时照常列出；
  - 搜不到时的提示恢复「设备附近没有搜到2.4G WiFi，请重新搜索或手动输入WiFi名称」，控制台日志同步。
- `subpackages/device/wifi-config`（账号密码页）：表单上方恢复同款提示条及样式；表单的 `margin-top: 36rpx` 去掉，间距回到由提示条的 `margin: 24rpx 0 36rpx` 留出。
- 手动输入 WiFi 名称不校验频段（无从判断），与 10-27 之前一致。
- `tests/wifi-search.test.js`：分批用例恢复为 5G 被过滤、只留 2.4G；空列表提示断言改为含 2.4G；两页模板断言改为必须有 2.4G 提示条与 `.wifi-tip` 样式，选择 WiFi 页标题断言改回「设备附近的2.4G WiFi」。
