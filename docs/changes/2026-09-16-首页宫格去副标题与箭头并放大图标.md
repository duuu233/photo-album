## 一、需求

产品原话：「首页页面下面的 6 宫格入口，去除副标题和右侧的箭头，把图标拉大，
主标题字号不变，整体效果要合适得体。」

四件事：**删副标题**、**删箭头徽标**、**图标拉大**、**主标题字号不动**。

## 二、改法

### 1. 模板：卡里只剩两件

```xml
<view class="entry-card" …>
  <image class="entry-icon" src="{{item.icon}}" mode="aspectFit" />
  <view class="entry-name" style="color: {{item.color}}">{{item.name}}</view>
</view>
```

删掉的是 `.entry-copy` / `.entry-text`（「标题+副标题」与箭头并排的那层壳）、
`.entry-desc`（副标题）、`.entry-arrow`（右侧圆形箭头徽标）。

### 2. 样式

| 规则 | 改动 |
| --- | --- |
| `.entry-icon` | `66rpx` → **`96rpx`**（产品：把图标拉大） |
| `.entry-name` | 去掉 `margin-bottom: 8rpx`（那是标题与副标题的缝，留着整组会比卡片中线低 8rpx）。**`font-size: 28rpx` 一个数没动** |
| `.entry-card` | `padding: 0 12rpx 0 20rpx` → **`0 20rpx`**（右边那 12 是给箭头徽标的透明阴影留的，徽标没了就该左右对称） |
| `.entry-copy` / `.entry-text` / `.entry-desc` / `.entry-arrow` | 整条删除 |

**卡高 220rpx 不变**：副标题那一行（18rpx 文字 ≈26.4 + 8rpx 间距 ≈34rpx）腾出来的高度，
差不多正好就是图标放大的那 30rpx。改后整组 = 图标 96 + 间距 20 + 标题 ≈34 ≈ 150rpx，
`justify-content: center` 之下上下各余 35rpx，比改前（154rpx 内容、上下各 33）松一点点，
「合适得体」落在这里。

### 3. 数据：`HOME_ENTRIES` 每项只剩四个字段

`key / name / color / icon`。`desc` 与 `arrow` 两个字段删掉——留着死数据最容易让下一个人
以为「还在用」。**六张箭头素材 `home-icon11~16.png` 仍留在仓库里**备产品反悔，
由 `home.js` 的注释认领（见下）。

## 三、素材与回滚

`tests/unused-assets.test.js` 的规则是「没有活着的引用就不许留在 assets 里」，
所以六张箭头徽标进了该用例的 `parked` 白名单，认领它们的注释写在
`pages/home/home.js` 的 `HOME_ENTRIES` 上方（白名单会去核对那段注释还在不在）。

回滚办法：把 `desc` / `arrow` 两个字段、`home.wxml` 里对应的两个节点、
`home.wxss` 里那四条规则一起加回来即可；素材不用找。
真确认不再要了，请连同那段注释一起删、图也删掉（六张共 ~30 KB）。
