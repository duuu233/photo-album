# 隐私政策换成法务 v3.0 全文（小程序简中 / App 英文）（2026-08-13）

> 状态：current
> 最后核对：2026-08-13
> 适用范围：微信小程序（`subpackages/settings/privacy/*`）+ Flutter App
> （`lib/src/features/settings/presentation/privacy_policy_page.dart`）
> 权威来源：法务出具的 `docs/legal/privacy-policy(1).html`（简中）与
> `docs/legal/privacy-policy-en.html`（英文），两份都是 **v3.0，2026-08-13 生效**
> 相关：[2026-08-13 AI 与图库六项](2026-08-13-AI模块六项调整.md)（同意弹窗那句「详情请见
> 《BoltStar 隐私政策》第八节」指的就是这份文档）

## 为什么必须换

端上原来那份是 **2026-5-13 的旧短文**：两节、几百字，只讲「收集哪些信息 / 如何使用」。
而同日 AI 同意弹窗已经加上了境外传输告知，并写明「详情请见《BoltStar 隐私政策》**第八节**」——
旧短文根本没有第八节，**这句指路指不到任何地方**。这不是排版问题，是合规缺口。

法务给的 v3.0 是 14 章全文，含权限清单、共享清单、第三方 SDK 清单、跨境传输、收集清单四张表。

## 改法

### 小程序：正文进数据，页面只留一套通用渲染

14 章 + 56 条列表 + 4 张表写死进 wxml 是七百多行，下次法务再给一版就得重排一遍。所以：

| 文件 | 改动 |
| --- | --- |
| `subpackages/settings/privacy/privacy-content.js` | **新增**：由那份 HTML **逐块转换**而来的正文数据（`h2/h3/p/li/table` 五种区块 + 页首的日期/版本行）。文件头写明「勿手改，改动只能来自法务新 HTML」 |
| `subpackages/settings/privacy/privacy.wxml` | 整篇重写成一套通用渲染（`wx:for` + 区块类型分支），不再内联任何条款文字 |
| `subpackages/settings/privacy/privacy.wxss` | 新增 `.article-meta` / `.article-sub-title` / `.article-table*`（flex 手搭的表格） |
| `subpackages/settings/privacy/privacy.js` | 从 `privacy-content` 取数据进 `data`（顺带补 `wx:key` 用的稳定下标 key） |
| `tests/privacy-policy-content.test.js` | **新增**：14 章齐全、四张表行列对齐、**第八章确实讲跨境传输**（弹窗那句指路要落到实处）、页面把五种区块都画出来了、旧版日期不再写死在页面里 |

⚠️ 转换时**丢掉了文档里的目录（TOC）**：那 14 条是 `#sN` 锚点，wxml 没有锚点跳转能力，
照抄只会多出一屏点不动的链接。正文一字未改。

⚠️ 表格是 flex 手搭、列宽均分，**行高与列宽都不能写死**：权限说明、SDK 名称、收集场景都会折行。

### Flutter App：固定英文

产品口径：**App 的隐私政策一直显示英文，不随语种设置变化**。法务只出具了英文版，
其余语种没有经审阅的文本 —— 机翻一份法律文本摆进设置页，比只给英文更糟。

| 文件 | 改动 |
| --- | --- |
| `privacy_policy_page.dart` | 整页重写：正文是**编译期常量** `privacyPolicySections`（14 章），**不走 `AppL10n.pick`**；页面标题仍随语种（那只是入口名字，不是条款） |
| `legal_document_view.dart` | `LegalSection` 增加 `blocks`（`LegalText` 段落/要点/小节标题 + `LegalTable` 表格），并新增表格渲染：列宽不写死，**列多到一屏放不下时整张表横向可滚**（把字挤成一列一个字才是真的没法读）。原有 `body:` 用法不变，用户协议/AI 服务协议两页一字未动 |
| `test/privacy_policy_content_test.dart` | **新增**：14 章齐全、第八章是跨境传输、四张表行列对齐（Flutter 的 `Table` 行列不齐会直接抛断言）、正文里不得出现中文（＝没被 l10n 化）、英文弹窗那句 `Section 8` 指得到 |

🔶 有意保留的一处不一致：页首「更新日期 / 生效日期」的**标签**仍随语种（`setUpdatedDate`），
日期值是英文原文。标签属于页面外壳，与条款正文不是一回事。

## 影响面之外的连带

- 小程序隐私页此前那份旧短文（含 `2026-5-13` 的日期）**已整体删除**；日期与版本号现在跟着
  法务文档走（页首一行「更新日期 / 生效日期 / 版本：v3.0」）。
- 两端的 AI 同意弹窗那句「第八节 / Section 8」现在都能落到实处，已由两端单测各锁一条。
