# 2026-11-06「我的设备」改 Tab 切换 WiFi版 / 蓝牙版

> 分支：`main-wifi`

## 需求

1. 设备列表页改成 Tab 切换，区分 WiFi版和蓝牙版，样式和交互参考投屏记录列表；
2. 没有设备时给一个默认图标，点击后跳到搜索设备页添加。

## 做了什么

`subpackages/device/list`：

- 2026-10-27 上下分组的标题（`.device-group-title`）删掉，改成顶部 Tab：「WiFi版」在前、「蓝牙版」在后。样式照投屏记录页的 `.record-tabs`：白色胶囊底、橙色滑动指示器（切到蓝牙版时平移一格，0.36s），选中白字；点击即切，本地按 `isWifi` 过滤，不重新请求，切换后回到页面顶部。
- 添加按钮从 Tab 上方单独一行（原来只在有设备时显示）移到 Tab 右侧，一直显示。
- Tab 下方「共 N 台设备」（同投屏记录页「共 N 条记录」），当前 Tab 有设备才显示。
- 当前 Tab 没有设备：显示默认设备图（`empty_device_art.png`，与首页空态同图），右下角压一个加号（`home-add-icon.png`），下面「暂无WiFi版设备 / 暂无蓝牙版设备」「点击添加设备」；整块可点，进搜索设备页（`goBind` → `subpackages/device/bind/bind`）。原「暂无电子纸设备 + 添加设备」卡片不再使用；「加载失败 + 重新加载」不变。
- 默认 Tab：普通模式 WiFi版；选相框模式（只能选蓝牙版）蓝牙版；默认那类没设备而另一类有，就落到有设备的那类；两类都没有时落在默认那类显示空态。用户点过 Tab 后，回到本页重拉列表保持所选，不再重置（不持久化，重新进页面按默认）。
- 卡片本身（WiFi 卡、蓝牙卡的内容、按钮、连接后置顶滚动）不变。

## 涉及文件

`subpackages/device/list/list.wxml`、`list.wxss`、`list.js`、`tests/device-list-wifi-group.test.js`。

测试：分组标题相关断言按 Tab 改写并注明（「有设备才显示该组」→ 默认 Tab 落在有设备的那类 / 当前 Tab 有设备才出列表；「WiFi 版在前」→ Tab 顺序），新增 Tab 默认 / 切换 / 重载保持 / 空态跳搜索页 / 选相框模式一组，以及指示器、选中色、加号定位的样式断言。
