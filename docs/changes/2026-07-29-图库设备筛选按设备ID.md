## Problem

图库页右上角设备下拉整条链路都以**设备名**为键：

- `buildDeviceFilters` / `buildDeviceFiltersFromDevices` 的筛选项 `value` 就是设备名，且按名去重；
- `applyFilter` 按 `photo.deviceName === filter` 过滤照片；
- `resolveUserProductId` 再用设备名反查 `userProductId` 去查一键清除状态。

两台设备名字相同时（设备名允许重复），下拉去重后只剩一个选项，两台设备的照片被混在一起筛出，一键清除状态也只能查到第一台。

## Solution

筛选项改为 `{ label: 设备名(仅展示), rawLabel: 原始设备名, value: 后端设备ID }`：

- 设备来源：`value = device.userProductId || device.id`；照片来源：`value = photo.deviceId`（api.js `normalizePhoto` 里就是后端 `userProductId`），全程按 ID 去重/合并。
- `applyFilter` 按 `photo.deviceId === filter` 过滤；老照片没有 `deviceId` 时按当前筛选项 `rawLabel`（原始设备名）兜底匹配，避免筛不出来（同名设备下这类照片会两边都出现，无 ID 无从区分，接受降级）。
- 同名设备消歧（`disambiguateFilterLabels`）：重名时 label 补序列号（deviceNo）尾 4 位，如 `客厅相框(D428)`；无序列号则按出现次序补 `(2)`/`(3)`。
- 筛选按钮文案改用新 data 字段 `currentFilterLabel`（`currentFilter` 现在是 ID，不能直接展示）。
- `resolveUserProductId` 整个删除：筛选值本身就是 `userProductId`，`checkDeviceClearStatus` 直接用。
- 附带修正：设备改名后老照片（带旧名但有 ID）现在按 ID 归到改名后的设备项下，不再多出一个旧名筛选项。
