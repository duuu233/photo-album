# 详情页「固件升级」右侧改回版本号 + 箭头旁新版本红点（2026-08-20）

> 状态：**小程序端已实现**，**未真机验收**
> 最后核对：2026-08-20
> 适用范围：微信小程序设备详情页（`subpackages/device/detail`）
> 上一版：[2026-08-12 固件升级行改版本比对结论](2026-08-12-固件升级行改版本比对结论.md)（右侧文案部分被本次取代，判定函数继续沿用）
>
> ⚠️ 仅小程序，Flutter APP 待同步（App 侧详情页同一行需核对是否也在展示比对文案）。

## 一、产品要求

「固件升级」行右侧**就显示设备当前的版本号**；如果检测到有新版本，**在右侧箭头附近点一个红点**即可。
不再用「有版本可更新 / 已是最新版本」两句文案占着右侧。

## 二、改动前的行为（2026-08-12 版）

右侧显示的是比对**结论文案**：`有版本可更新` / `已是最新版本` / `--`。
用户看不到设备当前在跑的是哪个版本，报障时也说不出版本号。

## 三、改法

右侧一行拆成两件事：**版本号（文字）** 与 **有无新版本（红点）**，判定函数 `evaluateFirmwareUpdate`
原样保留不动，只是消费方式变了。

### 1. 右侧版本号：`firmwareVersionText(device)`

只认**设备实际在跑的版本**——调试台「读固件版本」那条路（`0x03 GET_SW_VER`，详情页由
`deviceInfo.read` 一并读回，落在 `device.firmwareVersion`）。

- 未连接 / `0x03` 没读到 → 回落 `'--'`，与本页设备ID、最大照片数量、轮播设置同一套占位约定；
- **不拿接口的 `newVersionNo` 顶上**：那是云端最新版本号，显示出来就是一个假的「当前版本」，
  也正是 2026-08-12 那次改动要解决的问题。

### 2. 箭头旁红点：`hasFirmwareUpdate(device)`

红点亮 ⟺ 点进去真的能升级，判定与 `goOtaUpgrade` **完全同源**（含 unknown 回落分支）：

| `evaluateFirmwareUpdate` state | 条件 | 右侧版本号 | 红点 | 点击「固件升级」 |
| --- | --- | --- | --- | --- |
| `update` | 版本号不同 + `downloadPath` 有效 `.bin` | 设备当前版本 | **亮** | 二次确认「检测到新版本：X，是否升级」 |
| `latest` | 版本号相同，或接口没给 `newVersionNo` | 设备当前版本 | 灭 | 弹「当前固件已是最新版本」 |
| `invalid` | 版本号不同但缺号/缺地址/不是 `.bin` | 设备当前版本 | 灭 | 如实说明原因（缺地址 / 不是 `.bin`） |
| `unknown` | 读不到设备当前版本（未连接 / `0x03` 失败） | `--` | 退回后端 `isUpdate`：`isUpdate=1` 且包有效才亮 | 同样退回 `isUpdate` 标志 |

两处必须同源，否则会出现「红点亮着、点进去弹已是最新版本」的自相矛盾。
`invalid` 不亮红点：后台数据有问题时点进去只会弹原因说明、根本升不了级，亮红点等于催用户去撞墙。

`unknown` 分支保住 2026-08-11 定下的「版本检测走接口、不连蓝牙也能查」能力——
未连接进详情页时版本号是 `--`，但后台说有更新照样亮红点，用户点一下就能查。

### 3. 断开连接后

版本号回落 `'--'`（与设备ID/内存/轮播设置一致），**红点按最后读到的版本 + 接口数据继续算**：
固件版本不会因为断开就变了，灭掉红点反而是把已知的「有新版本」藏起来。

### 4. 红点样式

`.firmware-dot`：14rpx 圆点、`#ff3b30`，纯提示不承载点击（整行本来就可点）。
`.row-right` 的 `gap` 是 16rpx，对「贴着箭头」来说太散，用 `margin-right: -8rpx` 往箭头收一半。

## 四、涉及文件

| 文件 | 改动 |
| --- | --- |
| `subpackages/device/detail/detail.js` | `firmwareUpdateText` → `firmwareVersionText` + 新增 `hasFirmwareUpdate`；data 字段 `firmwareUpdateText` → `firmwareVersionText` / `firmwareHasUpdate`（4 处 setData 同步）；删除已无人用的 `OTA_TEXT_UPDATE` / `OTA_TEXT_LATEST` |
| `subpackages/device/detail/detail.wxml` | 右侧由 `{{firmwareUpdateText}}` 改为 `{{firmwareVersionText}}` + `wx:if="{{firmwareHasUpdate}}"` 的 `.firmware-dot` |

| `tests/firmware-update-hint.test.js` | 改为同时钉住「版本号」与「红点」，新增「已连接读不到版本但后台 isUpdate=1 → 版本 `--` + 红点亮」等用例 |

`goOtaUpgrade` 的弹窗流程，`subpackages/device/ota/ota.js` 的 `buildFirmwareFromDevice`。
