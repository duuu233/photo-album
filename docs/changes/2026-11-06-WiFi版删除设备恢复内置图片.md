# 2026-11-06 WiFi 版删除设备：恢复内置图片

> 分支：`main-wifi`｜依据：接口文档口径——新增 `POST /api/device/restore-builtin`（JSON：`deviceNo`、`renderMode`，Header `userToken`）

## 做了什么

- `utils/iot-api.js` 新增 `restoreBuiltin({ deviceNo, renderMode })`：`POST /api/device/restore-builtin`，`deviceNo` 去冒号大写（同其它 IoT 接口），`renderMode` 有值才带、原样传。
- WiFi 详情「删除设备」（`subpackages/device/wifi-detail/wifi-detail.js` 的 `confirmDeleteDevice`）流程改为：
  ① 清相册记录 `clearUserProductImg` → ② 删全部云端照片 `photo/delete all=true` → **③ 恢复内置图片 `restore-builtin`** → ④ 删设备 `delUserProduct`。
  `renderMode` 与投屏同口径取后台产品配置（`api.resolveRenderMode`：设备记录自带 → productId 查产品列表 → `getProductByDevice`），取不到不传。
- ③ 失败：提示「恢复内置图片失败：原因」，不删设备，确认弹窗保留可重试；成功才继续删设备。
- 解除绑定不调该接口（仍只删设备记录）；蓝牙版删除流程不变，不调。
