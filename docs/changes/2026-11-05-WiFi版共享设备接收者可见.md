# 2026-11-05 WiFi版共享设备：入口改名、接收者可见

> 分支：`main-wifi`｜依据：产品要求设备详情「分享设备」改叫「共享设备」，接收者也能进，看到的内容与所有者一致，只是没有移除和分享设备按钮

## 做了什么

| 位置 | 改动 |
|---|---|
| WiFi 详情 `wifi-detail` | 功能栏「分享设备」改名「共享设备」，去掉「仅所有者」限制，接收者也显示、也能进；「删除设备」仍仅所有者 |
| 共享设备列表 `wifi-share` | 页面标题改「共享设备」。身份按设备详情判断（`wifiShare.isOwner`：`isToHave=1` 或没有 `shareUserId` 是所有者），不看入口参数。接收者看到的内容同所有者（所有者栏 + 「已分享」成员列表，成员列表里也有自己），但不显示每行的「移除」，也不显示底部「分享设备」按钮、提示语和开发版「复制测试参数」；对应方法里也按身份拦住 |
| 接收者进页面 | 不画分享卡片封面、不取个人资料和服务器时间戳；右上角转发退回小程序首页卡片。成员接口返回里没有所有者那条时，所有者栏不显示（不再拿当前用户兜底，否则接收者会被显示成所有者）；所有者本人进来仍按原来兜底 |

底部按钮文案仍叫「分享设备」（只有所有者能看到）。
