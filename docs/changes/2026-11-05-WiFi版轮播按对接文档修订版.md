# 2026-11-05 WiFi版轮播按对接文档修订版：简单模式卡片、选图弹层、时区本地化、下次刷新卡片类型

> 分支：`main-wifi`｜依据：`docs/wifi/前端对接文档20261105-1.md`（第二版，与 `前端对接文档20261105.md` 冲突以它为准）

## 做了什么

| # | 位置 | 改动 |
|---|---|---|
| 1 | 轮播设置 `wifi-slideshow` 选图 | 简单模式的照片不再在页面里铺开，改为「轮播照片 · 已选 N 张 ›」一行，点开与高级卡片同一个底部弹层。弹层从下往上滑入（全局 `popSheetSlideUp`）、下滑退场（`.pop-closing-sheet`），时区弹层同样；每行 3 张，格子同「我的上传」（高 210rpx、圆角 22rpx、浅蓝底、aspectFit，右上角圆圈选中后橙底显示顺序）；照片按页取、每页 21 张（`getProjectionRecordsPage`），弹层每次显示 21 张，滑到底再显示下一页；最多 100 张，选满置灰并提示 |
| 2 | 时区 `utils/time-zone.js` | 展示改为按语种（`utils/language` 的简中 / 繁中 / 英 / 日）显示「国家 / 城市」，如「中国 / 北京」「美国 / 纽约」，去掉「（UTC+8）」；下拉列表每行只有这一段文字（去掉右侧中文副标题），分组名也按语种，港澳台并进「中国」组；提交值仍是 IANA 名，展示文案与提交值两套数据；不在候选里的时区原样显示 IANA 名；搜索认 IANA 名与四种语种的译名 |
| 3 | 我的设备 WiFi 卡 / WiFi 详情「轮播设置」 | 去掉「轮播中」文字标签，保留右上角绿点动效，轮播图标换成绿色版（`assets/images/device-detail-icon01-on.png`）；只在 `running == true` 且设备状态在线时显示 |
| 4 | 轮播状态 | 「最后设置 …」改为「设置时间：yyyy-MM-dd HH:mm」，与「下次刷新：」同一格式 |
| 5 | 下次刷新 | 「下次刷新：MM-dd HH:mm · 卡片类型」：`nextRefreshCardType` 为 `weekday` / `weekend` / `anniversary` 显示「工作日 / 周末 / 纪念日」；`base` 按当前轮播方式，间隔取 `intervalMinutes`「每 N 分钟 / 每 N 小时」，固定取 `updateDays`「每天（=1）/ 每 N 天」，字段为 `null` 不带后缀；`nextRefreshAt` 为 `null` 整行不显示 |
| 6 | 固定模式每 N 天 | 选项 1~30（显示「每天 / 每 N 天」，行名改「播放频率」），超出不让保存；存量配置 > 30 原值回显并红字提示「当前播放频率为每 N 天，已超过 30 天上限，请调整后再保存」 |
| 7 | 纪念日 | 日期选择改为月 / 日两列（不选年），日这一列随月份变：2 月 1~28，4 / 6 / 9 / 11 月 1~30，其余 1~31；删掉「02月29日只在闰年生效」，说明改为「只支持公历，只选月和日」 |
| 8 | 保存条件 | 简单模式启用，或至少一张高级卡片启用（工作日 / 周末开关、任一纪念日）才能保存；都没有时「保存并开始轮播」置灰，点了提示「至少配置一项」 |
| 9 | 简单模式卡片 | 原基础配置做成「简单模式」卡片，带启用开关，默认启用并展开；关闭后卡片收起，不提交基础字段（间隔的 `timingTime` / `beginTime` / `endTime`，固定的 `updateDays` / `updateTimeList`，以及基础 `mode` / `imgUrls`）；回显时当前模式的基础字段为空即为关闭。固定模式下 `updateDays` 只跟着 `updateTimeList` 带。工作日 / 周末启用时的三档提示挪进简单模式卡片，文案「本配置」改「简单模式」，高级卡片说明同步改名 |

自行决定（可改）：

- 「轮播中」绿色图标与绿点按「轮播中且在线」同时出现；轮播设置页自身的「轮播状态：轮播中」文字不动。
- `base` 的小时档按「每 N 小时」显示（含「每 1 小时」），只有天数按文档把 1 显示为「每天」。
- 纪念日后缀只显示「纪念日」，不再附 `nextRefreshCardMonthDay`（前面的时间已带月日）。
- 时区译名：中国 / 北京、中国 / 香港、中国 / 澳门、中国 / 台北，新加坡只写一段；英文用 USA / UK / UAE 等简称。
- 进页把这台设备的可轮播照片按每页 21 张取完（最多 30 页），回显校验、全选、「全部相册」判断仍按整本相册；原来一次取 100 条，超过 100 条的照片选不到，现在能选到。
- 简单模式关闭时保存成功只提示「已保存，屏幕即将刷新」。
- 「开启轮播必须至少选一张」沿用：简单模式启用时它和每张启用的卡片都至少一张。
