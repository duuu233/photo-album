# 2026-11-03「我的上传」切后台回来不重新加载

> 分支：`main-wifi`

## 原因

页面 `onShow` 每次都跑 `loadPhotos`（`getDevices` → `applyFilter` → `loadRecords`），`loadRecords` 先清空网格、置 `loading`，所以切出小程序再回来必闪「加载中」，已选与已翻的页也被清掉。不是微信机制：小程序切后台一段时间内页面实例和 data 都还在。

## 做了什么

- `onShow` 按来源处理（`subpackages/album/list/list.js`）：
  - 首次进页 / 还没成功加载过：正常加载；首屏请求在途时再 `onShow` 不重复发。
  - 本页在前台时切后台（含选图等系统界面）且 10 分钟内回来：沿用已加载的照片、已选、翻页，**不发请求**。
  - 从下一级页面返回（再次投屏、预览等可能多了新记录，在那边切过后台也算）或后台超过 10 分钟：**静默刷新**——不清网格、不转圈，回包后整表替换。
- 「切后台」的判定：`onLoad` 注册 `wx.onAppHide`（`onUnload` 取消），本页 `onHide` 与 `onAppHide` 时间相差 1.5 秒内才算本页在前台时切了后台；只有页面 `onHide` 的是进了下一级页面。
- 静默刷新：已翻到第 k 页就一次取 `k × 21` 条（`pageIndex=1`），之后第 k+1 页仍按每页 21 条接着取（后端少回时按实际整页数接，重叠部分按 id 去重）；已选里仍在列表中的保留；设备列表或记录接口失败保留现有内容、不切「加载失败」；当前设备已不在设备列表（被解绑）才按正常流程切到新默认设备。
- 一键清除状态（`getUserProductClearImg`）在静默刷新时照常查，切后台回来不查。
- 删除后、「重新加载」、切设备仍是正常加载（转圈），不变。
- 控制台：`[我的上传] 切后台回来，沿用已加载的照片，不重新请求` / `… 静默刷新`；静默刷新的记录日志带 `[静默刷新]`。

## 涉及文件

`subpackages/album/list/list.js`、`tests/album-cache-on-show.test.js`（新增）。
