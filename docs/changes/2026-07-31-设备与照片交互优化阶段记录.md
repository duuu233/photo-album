# 设备与照片交互优化阶段记录

> 日期：2026-07-31  
> 状态：已实现，待真机回归  
> 停止点：按用户指示，Flutter 第 16 项完成后停止，不继续后续编号

## 本轮小程序实现

- 设备名称统一为最多 20 个 Unicode 字符；首页、设备列表、详情、图库及投屏设备选择均以单行省略号承载长名称。
- 新绑定设备成功后在绑定页带出默认名称，用户可保存或暂不修改，再按原逻辑返回。
- 设备列表按“已连接、最近绑定、其余设备”排序，切换连接设备时增加上移动效。
- 蓝牙不可用提示统一为“请检查并打开手机或小程序蓝牙开关”。
- “我的图库”改为“设备照片”，新增当前屏幕照片说明，并加宽设备下拉框。
- 图库允许清理设备端已经异常缺失的照片记录，提示“照片在此设备异常，请删除重新上传”。
- 轮播页以完整设备身份继承活动会话，修复已连接设备仍提示先连接的问题。
- 设备详情区分“解除绑定”和“删除设备”：前者保留照片；后者经两次确认后执行清空、断开和解除绑定。
- 设备详情将“分辨率”改为“屏幕尺寸”，将容量项改为“最大照片数量”，并更新清空提示。
- 投屏记录按设备筛选，默认优先当前真实连接设备。
- 照片预览支持自由缩小、白底所见即所得、长按 0.5 秒单指移动及 360ms Banner 切图。
- 个人昵称兼容真实 emoji、Unicode 转义和 HTML 数字实体显示。

## Flutter 已完成范围

- 设备名称校验和列表/详情输入长度统一为 20 个 Unicode 字符。
- 我的设备列表与设备详情页保存名称时，iOS/Android 共用的 Flutter 流程均显示“保存中”阻断式 loading，并在成功、失败或页面切换时可靠关闭。
