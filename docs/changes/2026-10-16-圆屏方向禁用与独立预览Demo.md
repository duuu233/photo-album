# 2026-10-16 圆屏方向禁用与独立预览 Demo

## 需求

产品需要能在微信开发者工具直接打开、截图且和正式照片预览同逻辑的独立 Demo；同时正式页和 Demo 的圆形设备横竖向选择需置灰，因为圆屏无此取景方向区别。

## 实现与边界

- 新增 `subpackages/projection/preview-demo/preview-demo` 独立路由，默认圆屏500×500，可用 `shape=rectangle` 对比480×720方屏。两张固定网图不含业务图片或用户数据。
- 原预览逻辑原位提取到同目录 `preview-page.js` 工厂；正式 `preview.js` 仅负责注册，Demo 直接复用工厂，不导入注册页面或复制一套近似手势。WXML include / WXSS import 正式文件，因此截图布局与圆形样式一致。
- 正式初始化只拆出 `readPreviewInput` 与 `warmupPreview` 接入点，仍读取原待投屏 Storage、恢复快照、预热连接和 Token。Demo 覆盖这些边界及持久化/最终提交，使用本页数据、不连接设备或改业务 Storage，点击开始投屏仅用原出图逻辑生成本地预览。
- 圆形判断继续只认数字 `shapeType === 1`：横竖向禁用灰态、去按压反馈、隐藏选中滑块，`setOrientation` 也直接返回；原图还原、图片旋转与手势不禁用。方形/缺失/其它值沿用原路径。
- 开发版允许进入 Demo，体验版/正式版返回首页。未增加业务首页入口，不改变原 App 启动和全局固件检查。
- 共享及现有本机编译条件均追加圆屏/方屏Demo，保留原条目，不切换默认首页或修改线上域名白名单。操作手册见 `docs/preview-demo.md`。
