# 投屏管理 Tab 即时切换与列表局部 loading

> 状态：current-change-record  
> 日期：2026-07-29  
> 适用范围：微信小程序 `subpackages/projection/records`

## Problem

成功/失败 Tab 点击后，旧实现先等待 `getProjectionRecords` 返回，随后才把 `filter` 写入 data。
接口较慢时 Tab 指示器没有变化，用户会误以为点击无效；快速连续切换还可能被较早请求的迟到响应覆盖。

## Solution

- 点击即同步写入 `filter`，Tab 和指示器立即切换。
- 只把下方列表区替换成 loading，顶部 Tab 始终可见、可继续切换。
- 每次请求分配 `loadSeq`，仅最新 Tab 对应的响应允许回写；页面卸载时一并作废在途响应。
- 失败时在当前 Tab 的列表区展示“加载失败 / 重新加载”，不伪装成空列表。

## Affected Areas

- `subpackages/projection/records/records.js`
- `subpackages/projection/records/records.wxml`
