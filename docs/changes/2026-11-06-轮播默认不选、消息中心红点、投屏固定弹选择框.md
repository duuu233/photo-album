# 2026-11-06 轮播默认不选、消息中心红点、投屏固定弹选择框

> 分支：`main-wifi`

## 1. 轮播设置 · 简单模式 · 轮播照片默认不选

- 原来：服务端回显 `imgUrls` 为 null 就按整本相册全选——没配置过的设备进来也是全选。
- 现在（`utils/wifi-strategy.js` `selectionFromStrategy`）：只有简单模式确实保存过（`configured` 且基础字段在）时，null 才是用户保存的「全部相册」，照旧回显全选；没配置过、或只配过高级卡片（简单模式没保存）一律不选，由用户自己挑。开启轮播仍要求至少选一张。
- 高级卡片（工作日 / 周末 / 纪念日）的选图口径未改。

## 2. 设备详情 · 消息中心：未读改红点

- WiFi 设备详情「消息中心」一行有未读时只亮红点（同固件升级行 `.wifi-detail-dot`），不再显示具体数字；去掉 `unreadText` 与 `.wifi-detail-badge`。未读数查询不变。
- 消息列表页（`wifi-messages`）不变。

## 3. 官方图库 / AI 生图：点投屏固定弹设备选择框

- 取消「已连上蓝牙设备就直接进投屏」：图片详情页 `onProject`、AI 对话 `projectImage` 一律先弹「选择投屏设备」。没绑定任何设备的判断与提示「暂无已绑定电子纸设备，请先绑定电子纸设备」不变。
- 弹层主按钮「连接并投屏」改为「投屏」（组件默认文字，两页都用默认）；蓝牙版按下后照旧先连上再进预览。
- 每行带连接状态（设备名下一行，圆点 + 文字）：WiFi 版查一次云端状态，显示「在线 / 离线 / 休眠中 / 已关机 / 本地模式 / 状态未知」（同我的设备），在线青绿；蓝牙版看本机有没有这台的活动会话，「已连接」蓝 /「未连接」灰。
- 为了显示「离线」，所有已绑定设备都进列表：原 2026-10-29「离线 / 本地模式 / 状态未知的 WiFi 版不进列表」与「暂无可投屏的电子纸设备」提示取消。选了不可投的 WiFi 版，按「投屏」后照旧由 `wifiStatus.ensureOnline` 提示（离线 / 休眠 / 关机 / 本地模式）并停在本页；预览页「开始投屏」的严格判断不变。
- 两页原来各写一份的行映射收进 `utils/picker-devices.js`（`buildPickerDevices`）；`wifiStatus.filterPickable` 保留未删，目前没有调用方。
