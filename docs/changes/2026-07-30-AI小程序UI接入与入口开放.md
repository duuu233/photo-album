# AI 小程序 UI 接入与入口开放

> 状态：current-change-record  
> 日期：2026-07-30  
> 适用范围：微信小程序  
> 官方图库：本轮不接入  
> Flutter：本轮不修改

## 目标

- 按 `assets/ai/UI` 的视觉稿重写 AI 对话与历史会话页面。
- 使用已英文命名并迁移至 `assets/images/ai-*.png` 的现有图片；缺失图片继续使用色块占位。
- 开放小程序 AI 正式入口，移除仅供内部验收的调试口令。
- 保持现有 BoltStar API、AI 服务协议、会话懒创建、发送去重、图片上传与统一投屏链路不变。

## 实现

- 自定义底栏调整为“首页 / AI对话 / 我的”三项；AI 仍是分包页面，以 `navigateTo` 进入。
- 聊天页改为视觉稿中的顶部历史入口、会话标题与 Token 余额；底部使用常驻相册、拍照、方向和一键生图工具卡。
- 生图方向与风格使用靠近输入区的浮层；图片长按后显示下载、投屏、删除内联操作条。
- 30xxx/未知上游失败保留为可见失败卡，支持原请求参数重试；封禁、参数、网关白名单错误仍走原错误分发。
- 投屏设备选择改为底部弹层，选择后继续复用 `pendingProjection → projection/preview` 链路。
- 历史会话按日期分组；支持左滑露出删除按钮，并保留长按删除兜底。
- 调试台的 AI 暗门常量、输入框和样式已删除。
- `assets/ai/UI` 仅用于设计对照，已加入 `project.config.json` 打包忽略；运行图标已统一迁移到 `assets/images/ai-*.png` 并正常进入运行包。
