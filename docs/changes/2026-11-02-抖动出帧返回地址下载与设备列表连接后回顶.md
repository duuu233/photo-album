# 2026-11-02 抖动出帧返回地址拼 download-endpoint 下载 / 设备列表连接后回顶

> 分支：`main`（`main-wifi` 经合入 main 同步）｜依据：产品口径

## 一、抖动出帧：接口返回地址，拼 download-endpoint 下载

- 出帧接口保持 `https://api.yikaltd.com/api/Client/Basic/imageDitheringBinDownload`，参数不变（同日先误把接口地址整个换成了 download-endpoint，已撤回）。
- `utils/dithering.js`：接口返回成功 JSON（`retCode=200`，或 `code` 为 0/200）且带地址时，按 `https://iot.boltfox.cn/api/device/download-endpoint` + 返回地址**直接拼接**，`GET`（`responseType: arraybuffer`）下载帧 bin，再交给调用方做「字节数 = 宽×高÷2」校验。
  - 地址取值：`retData` / `data` 本身是字符串，或其中的 `url` / `path` / `binUrl` / `fileUrl` / `downloadUrl` / `filePath` / `fileName` 字段（以后端实际字段为准，联调后可收窄）。
  - 成功却没有地址按「图片转化失败」处理；下载网络失败退避重试 3 次，下载回 JSON / 非 200 / 空体按失败处理。
  - 接口仍直接回二进制帧时照旧原样使用。
- ⚠️ 小程序后台「request 合法域名」需包含 `https://iot.boltfox.cn`。

## 二、我的设备：蓝牙设备连接后平滑滚回顶部

- `subpackages/device/list/list.js`：连接成功（`applyConnectedDevice`）后，连上的设备已排到第一张并播上浮动效，现在同时 `wx.pageScrollTo({ scrollTop: 0, duration: 300 })` 把页面平滑滚回顶部，停在下方点连接也能看到那张卡。「连接」与「投屏」按钮触发的连接都会滚。
