# 2026-11-06「我的上传」删除去掉「未找到所属设备」拦截

> 分支：`main-wifi`｜依据：后端口径（删除相册记录接口已支持删除这台设备上所有人上传的记录）

## 原因

2026-11-03 起「我的上传」按设备 ID 查投屏记录，能查到这台设备上**所有人**上传的照片。共享成员上传的、或自己解绑重绑前上传的记录，带的是上传人自己那条绑定的 `userProductId`，本人设备列表里没有；删除前找设备时据此提示「未找到照片所属电子纸设备，请刷新后重试」并拦下，刷新也没用。

## 做了什么

- `subpackages/album/list/list.js` 新增 `resolveOwnerDevice(ids)`，删除与再次投屏共用。每条记录依次按：① 记录的 `userProductId` 对上本人设备；② 记录的完整设备 ID（`productDeviceId`）对上本人设备；③ 都对不上 → 当前设备下拉选中的那台（列表本就是按这台查出来的）。
- `ensureConnectedDevice` 去掉「未找到照片所属电子纸设备，请刷新后重试」；`ownerIfWifi` 改用同一套归属，WiFi 版里共享成员的照片也走 WiFi 删除（删记录 + 删云端）。
- 「只能操作同一台电子纸设备的照片」保留，但按归属后的设备比，不再按原始 `userProductId` 比：自己的和共享成员的照片一起选也能删。
- 再次投屏用的是同一个归属，共享成员上传的照片也能再次投屏到当前这台。

## 涉及文件

`subpackages/album/list/list.js`、`tests/album-wifi-delete.test.js`。
