# 2026-11-03「我的上传」投屏记录每页 21 条

> 分支：`main-wifi`

## 做了什么

- 「我的上传」页（`subpackages/album/list`）的投屏记录接口 `getUserProductImgRecordList` 改为每页 21 条（`pageSize=21`，3 列 × 7 行），原来只取第 1 页 100 条。
- 页面滑到底（`onReachBottom`）加载下一页并追加到网格末尾，查询条件沿用首屏（同一台设备、带不带 `deviceId` 同首屏）；已选照片保留；按记录 id 去重；切设备 / 删除后从第 1 页重新取，旧请求回包丢弃。
- 网格底部显示「上拉加载更多 / 加载中… / 没有更多了」，只有一页时不显示；下一页失败显示「加载失败，点击重试」，已加载的照片不清。
- 是否还有下一页：先看分页元数据 `pageCount`，再看 `recordCount`，都没回才按「本页满 21 条」判断。
- 「共 N 张」：第一页全是成功记录时用后端 `recordCount`（后端已按 `deviceUploadState=1` 过滤），否则按已加载的成功张数。
- 「全选」只选已加载的照片；WiFi 删除时的 `nextImageUrl` 仍取已加载列表中剩下的第一张。
- 新增 `api.getProjectionRecordsPage`（返回 `{ records, rowCount, recordCount, hasMore }`）；`api.getProjectionRecords` 改为调它取第 1 页 100 条，投屏记录页、WiFi 轮播设置选图行为不变。
- 控制台 `★★★【我的上传·deviceId】` 日志补上页码、是否还有下一页。

`utils/api.js`、`subpackages/album/list/list.js` / `.wxml` / `.wxss`、`tests/album-records-paging.test.js`（新增）、`tests/album-records-device-id.test.js`、`docs/reference/client-api-matrix.md`。
