# 2026-11-06「我的上传」删除写请求日志

> 分支：`main-wifi`

## 原因

删除时页面只在控制台记摘要（设备掩码、`0x12`、记录删除结果、云端返回），看不出调了哪个接口、带了什么参数；网络层的 `[HTTP]` / `[IoT]` 那一行只进联调日志浮窗，不进控制台。

## 做了什么

- `api.deleteProjectionRecords(ids, { onLog })`：逐条记 `接口【删除相册记录】POST /Client/UserProduct/delUserProductImgRecord 参数 {"id":…}`，结束记 `→ 返回 …` 或 `→ 失败 code message`。不给 `onLog` 行为不变。
- `iotApi.deletePhotos(payload, { onLog })`：记实际发出的 body（`deviceNo` 已去冒号，`imgUrls`、`nextImageUrl` / `all`）`接口【删除云端照片】POST /api/device/photo/delete 参数 …`，结束记返回或失败；失败照旧抛出，其余选项照常交给请求层。
- 「我的上传」页（`subpackages/album/list/list.js`）两条删除链路都传 `onLog`，打进 console（开发版 / 体验版浮窗也能看到）：
  - 蓝牙版前缀 `[相册删除]`，记录删完再记一行 `记录删除结果 {total, failed, failedIds}`；
  - WiFi 版前缀 `[相册删除][WiFi]`，记录与云端两个接口都记；原「云端删除返回」一行并入请求日志，云端失败的 warn 保留。
- 删除流程、提示文案不变；WiFi 详情「删除设备」的 `photo/delete all=true` 不在本页，未加。
