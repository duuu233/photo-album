# 搜索列表只展示本次核实设备ID

日期：2026-10-21。环境：home；业务分支main，起点86a6611。用户明确搜索列表不使用兜底或缓存，无法确认则显示--；进一步确认“未核实的ID显示--，连接后读取真实ID”。

## 行为

- 搜索阶段所有设备的ID为--，即使广播能解析出4/6字节ID也不直接显示。移除蓝牙连接地址兜底，列表始终保留ID行。
- 只在用户连接当前设备、本次0x01返回合法完整6字节ID后更新该行。每次读取前清空旧显示；失败、缺失、短ID、全0和全FF不回退其他来源。
- 重新搜索清空列表、选择和已核实显示；扫描回包与本次读取按搜索序号隔离，旧结果不回填新列表。
- 搜索页的freshOnly订阅只接受加入扫描后新收到的广播；共享扫描之前存下的设备不会直接带出。硬件扫描仍共享，不抢占别的订阅者。
- 修正ID单独变化时不触发列表更新的遗漏，最新广播缺ID时清除该字段，不合并旧帧。
- 不自动连接所有设备，不改变后续绑定的完整身份校验、投屏或OTA连接规则。
