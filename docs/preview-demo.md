# 照片预览独立截图 Demo

> 状态：current
> 最后核对：2026-10-16
> 适用范围：微信开发者工具 / 开发版；体验版、正式版不开放

## 打开方式

1. 用微信开发者工具打开本项目，等待代码加载完成。
2. 在顶部编译模式下拉里选择 **圆形照片预览 Demo**，点击编译。默认模拟 500×500 圆形设备，两张网图可左右切换。
3. 等照片显示后，直接使用模拟器的截图功能。页面没有额外调试栏，导航、取景框、底部操作区均为正式照片预览页。
4. 对比方形时选择 **方形照片预览 Demo**，模拟 480×720 设备，横竖向仍可切换。

两个配置文件均已追加演示编译条件，并保留原有照片预览条件和其它设置。若本机编译列表没有更新，可手动新建条件：

| 项目 | 值 |
| --- | --- |
| 启动页面 | `subpackages/projection/preview-demo/preview-demo` |
| 圆形参数 | `shape=round`（不传参数也默认圆形） |
| 方形参数 | `shape=rectangle` |

无需登录、连接设备或往 `pendingProjection` 填假数据。演示图来自 `images.unsplash.com`；当前两张图已只读验证返回 HTTP 200 / image/jpeg。工具里网图读取或导出失败时，确认网络可用，并在本地开发设置中勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。不要为演示修改线上域名白名单或关闭正式版校验。

## 和正式页一致的内容

- Demo 通过 WXML include、WXSS import 和同一个 `createPreviewPage` 内核，直接复用正式页，不另抄一套近似布局或手势。
- 圆形遮罩、按设备比例取景、长按 0.5 秒拖动、双指缩放/旋转、90° 旋转、按张编辑状态、滑动切图与原图还原都使用同一实现。
- 正式页及 Demo 均仅在数字 `shapeType === 1` 时，将「竖向 / 横向」置灰、去掉选中滑块/按压反馈并禁止切换；JS 同时拦截，不能绕过样式改变编辑状态。
- 「原图」、长按拖动、双指编辑和图片 90° 旋转仍可用。方形/未上报形状/其它值维持原行为。

## 演示边界

- 独立路由和独立输入，只使用演示设备、网图和本页编辑状态；不读写业务待投屏 Storage，不更改当前选中设备，不预热 BLE 或 seekink Token。
- 「开始投屏」在 Demo 中只复用正式出图逻辑，生成本地 JPG 并打开微信图片预览；不会去结果页、建业务记录或向设备发送。导出仍是物理分辨率完整矩阵，圆形只裁手机编辑预览，不把 JPG 裁成透明圆形。
- Demo 的开发版门禁不影响正式预览页。体验版/正式版直达 Demo 会返回首页，且不会初始化样例或进入编辑。
- 小程序仍使用原 App 入口；全局启动的日志、会话恢复或固件检测不由 Demo 改写。本页隔离不等于另建一套完全独立的小程序 App。

## 验证范围

- Node 回归覆盖圆屏/方屏的方向切换、编辑态/未就绪态、共享方法、数据隔离、开发门禁、原图与图片旋转、本地出图成功/失败和重复点击，以及编译入口。
- 已用本机微信开发者工具自带 `wcc` / `wcsc` 编译正式及 Demo 模板/样式（含 include/import），均退出 0。
- 尚未实际打开微信模拟器或真机验收截图、网图展示和完整触摸操作；编译通过不等同于视觉/真机验收。
