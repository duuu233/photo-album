二、服务内容

本应用为 BoltStar 电子纸相框（以下称“设备”）提供配套服务，当前包括：

  • 设备管理：通过蓝牙搜索、绑定、连接与重命名设备，查看设备电量、固件版本与容量，设置轮播播放模式与切换间隔，删除设备内的照片或一键清空。
  • 照片投屏：选择本地照片，经裁切、构图与画面转换后通过蓝牙传输至设备显示。
  • 我的相册：查看与管理已成功投屏的照片记录，支持多选删除。
  • 官方图库：浏览我们提供的图片素材、收藏并投屏。
  • AI 创作：文本对话、根据文字生成图片、上传图片进行美化，并可将生成结果投屏。
  • 星币：用于消耗 AI 能力的应用内虚拟道具，可在应用内购买。
  • 固件升级：检测并通过蓝牙为设备升级固件。

我们可能不时增加、调整或下线部分功能，具体以您所使用版本的实际展示为准。不同平台（iOS / Android / 微信小程序）的功能与支付方式可能存在差异。

三、账号注册、使用与注销

  1. 您需按页面提示完成注册与登录。您应保证所提供的手机号等信息真实、准确、合法有效，因信息不实导致无法使用服务或造成损失的，由您自行承担。
  2. 账号仅限您本人使用，不得出借、转让、出售或以其他方式许可他人使用。您应妥善保管账号及验证码，凡通过您账号实施的操作均视为您本人行为，由此产生的责任由您承担。
  3. 如发现账号被他人非法使用或存在安全漏洞，请立即通过第十五节的方式通知我们。
  4. 注销：您可在「我的 → 设置 → 用户注销」自助注销账号。注销后账号数据将被删除或匿名化，账号内的星币余额、投屏记录、AI 会话与设备绑定关系一并清除且不可恢复，未消耗的星币不予退还（法律法规另有规定的除外）。请您在注销前自行清空设备内的照片——注销后绑定关系解除，将无法再通过本应用删除设备中已显示的图片。

四、设备连接与使用规则

  1. 本应用通过蓝牙低功耗（BLE）与设备通信，设备同一时间仅支持一台手机连接。请在使用前确保设备已开机、电量充足并靠近手机。
  2. 操作系统要求 App 取得位置权限后方可扫描附近蓝牙设备，请您在系统提示时予以授权，否则将无法搜索到设备。
  3. 一台设备可被不同账号先后绑定。解除绑定或注销账号不会自动清除设备中已显示的图片，请您自行处理。
  4. 请勿在投屏或固件升级过程中关闭设备电源、断开蓝牙、退出应用或让手机息屏，否则可能导致本次操作失败。

五、照片投屏与内容规则

  1. 您仅可投屏您自行拍摄、创作或已合法取得授权的照片。您应对所投屏内容的合法性负责，不得投屏侵犯他人肖像权、著作权、隐私权或违反法律法规的内容。
  2. 受电子纸显示技术限制，设备呈现的色彩、层次与清晰度与手机屏幕存在差异，投屏画面需经过裁切、构图与色彩转换。该等差异属于技术特性，不构成产品质量问题。
  3. 投屏过程中会将您选择的照片上传至我们的服务器与图像处理服务用于画面转换，具体见《BoltStar 隐私政策》。
  4. 在应用内删除投屏记录不等同于删除设备内的图片，反之亦然，请按界面提示分别操作。

六、AI 创作服务

  2. 您在 AI 对话中主动发送的文字或图片，将传输至“火山引擎”AI 服务（由北京火山引擎科技有限公司提供）进行处理。发送的内容仅用于本次操作，不会被用于模型训练。

  6. AI 会话记录在服务端仅保留最近 7 天，到期自动清除，请您自行保存需要留存的内容。
